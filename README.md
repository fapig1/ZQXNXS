# ZQXNXS · 桌上有龙

增强现实课程设计：基于图像跟踪与行为状态驱动的移动 AR 萌宠互动系统设计与实现。

应用采用 Unity 6 LTS 主工程集成 Vuforia 图像跟踪、C# 互动逻辑与 uGUI 界面，由 Unity 输出 Android APK；Blender 负责角色模型和动画，Android Studio / adb 用于安卓调试。
