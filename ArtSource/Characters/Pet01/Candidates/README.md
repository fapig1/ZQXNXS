# 外部生成模型候选

把其他网站或软件生成的奶蛙模型放在本目录，每个网站、每次版本各建一个子目录。这里保存外部候选源文件，供后续比较造型、修整拓扑与骨骼绑定。

## 推荐格式

| 格式 | 建议 |
| --- | --- |
| `.glb` | 优先选择。通常能将网格、材质、贴图合在一个文件中，便于 Blender 导入与对照。下载后仍需检查实际是否包含贴图。 |
| `.blend` | 若软件能导出原生 Blender 工程，可直接提供；外部贴图请一并打包或放在同一候选目录中。 |
| `.fbx` | 可用，尤其适合已经带骨骼或动画的候选；同时保留外部贴图。 |
| `.obj` + `.mtl` | 可作为几何来源；请一并提供材质文件与贴图。OBJ 不包含骨骼和动画。 |
| `.gltf` + `.bin` + 贴图 | 也可用，请保持整个导出目录和相对路径完整。 |

每个候选提供一种完整格式即可，有选择时优先 GLB。只有 STL 时也能参考轮廓，但它不保留常用材质、UV 和绑定信息，不作为首选。

## 放置示例

```text
Candidates/
  README.md
  网站名_20260910_v01/
    model.glb
    preview.png              # 可选：该网站中的模型预览
    notes.txt                # 可选：网站名、生成日期、提示词、偏好与问题
  网站名_20260910_v02/
    model.fbx
    Textures/                # 保留下载的原始命名与目录关系
      ...
```

名称不必完全照抄。压缩包可保留在对应候选目录中；有多个文件时请保持它们原本的相对位置。

## 生成时便于后续绑定的条件

- 采用完整角色的自然站姿或轻微 A 字站姿，双脚分开，双臂与腹部留出可见间隙。
- 优先保持圆润丰满的肚子，以及自然的头身、手脚比例。当前标准参考为 [expression_frames.jpg](../../../../Docs/AssetReview/20260908_naiwa/expression_frames.jpg)，原始帧在 [video_frames](../../../References/20260908_naiwa_assets/video_frames/)。
- 尽量保留全身几何、材质与贴图，模型底座和背景可另外提供。最终米制尺寸可在 Blender 中统一。
- 可以提供未绑定模型。已有骨骼和动画时一并保留，导入后再检查是否适合当前角色和动作。

后续按候选实际情况检查多视角轮廓、手臂与腹部粘连、孔洞、重叠面、UV、材质和面数，再确定修模与绑定方式。生成网站里的预览与骨骼标签不能替代实际文件检查。
