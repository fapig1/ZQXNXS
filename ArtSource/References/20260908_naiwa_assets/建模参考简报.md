# 奶蛙建模参考简报（供 GPT + Blender 使用）

> 整理日期：2026-09-08
> 用途：为"桌上有龙"AR 项目主角（奶蛙风格圆润生物）的三维建模提供统一参考。
> 使用方式：将本文件与 `milkyfrog_official/` 下的姿态图一起提供给 GPT，再在 Blender 中逐步执行。
> 素材来源与版权说明见文末。

## 一、角色定位与风格

- 一只金黄色、体型极胖的直立小生物：小头、巨腹、短四肢，形象介于青蛙与恐龙幼崽之间。
- 整体气质：呆萌、慵懒、略带"抽象"喜感；表面光滑如黏土玩具/搪胶摆件，无毛发、无鳞片、无衣物。
- 参考体系说明：milkyfrog.com（设计版）与 naiwa.world（迷因版）两个来源的形象高度一致，可视为同一形象家族的两档"头身比"：
  - **设计版**（milkyfrog_official/）：头相对更大、造型更收敛 → **推荐作为 AR 主角基础**，远距离辨识度更好。
  - **迷因版**（naiwa_meme/）：头更小、腹更大、姿态更瘫 → 可作为夸张表情与动作的上限参考。
- 无官方三视图；本形象为左右基本对称的团状体型，背面可根据侧视图推断（背部为连续弧面，仅有一个小尾巴尖凸起）。

## 二、整体比例（按 AR 角色 20cm 总高设计）

以总高 H = 20 cm 为基准（milkyfrog 姿态图实测比例）：

| 部位 | 比例 | 20cm 换算 |
| --- | --- | --- |
| 总高（站姿，头顶到脚底） | H | 20 cm |
| 头顶到下巴（头部含于躯干） | ≈ 0.30H | 6 cm |
| 身体最宽处（下腹）宽度 | ≈ 0.72H | 14.4 cm |
| 肚皮最大前后径 | ≈ 0.62H | 12.4 cm |
| 腿长（髋到脚底） | ≈ 0.28H | 5.6 cm |
| 手臂长（肩到指尖） | ≈ 0.30H | 6 cm |
| 脚长 | ≈ 0.24H | 4.8 cm |
| 眼球直径 | ≈ 0.055H | 1.1 cm |
| 尾巴尖凸起 | ≈ 0.06H | 1.2 cm |

要点：

- **没有脖子**：头部直接融入躯干，从头顶到尾尖是一条连续的弧线（侧视最明显，参考 `mf-pose-lying.png`）。
- 身体质心低，下腹最宽；正面肚皮几乎贴地感。站姿为两条短腿微外八支撑。
- 头部从正面看约占全身高度的 1/3，其中眼睛位于头的上半部、偏前侧。

## 三、分部位建模要点

### 1. 头与躯干（一体成型）
- 用一个 UV 球或经 Sculpt 简单塑形：整体呈**竖置蛋形/梨形**，上部收窄成头，下部膨大成腹。
- 背部弧线：从头顶向后下方平滑过渡到臀部，途中在臀部后上方留一个小圆锥凸起（尾尖，钝圆）。
- 正面：胸部到下腹为一个大弧面；肚皮色块区域见第四节。

### 2. 眼睛（2 颗）
- 半嵌入头部的圆球，**不含眼皮结构**；眼白不可见。
- 结构：外圈黄绿色虹膜环 + 大黑色瞳孔 + 高光点。瞳孔极大，约占眼球可见面积的 60%。
- 位置：头顶部前侧，间距约一个眼球直径；从正面看双眼都朝前（略内聚的呆萌感）。
- 表情需要闭眼时，用**上眼睑（与身体同色的壳）下压遮住眼球**的方式实现（参考 `video_frames/mfstream_t2.png` 大笑帧），不要用贴图换脸。

### 3. 嘴
- 默认：一条细长的横向缝线（微弯、无唇部结构），位于头部下沿前方，宽度约为头部最大宽度的 60%。
- 大笑张开时：口腔内部深红色，**上颚一排白色小牙**（圆钝、不尖锐），可加粉红舌头；张口极大时嘴角几乎到头侧（参考 `mf-pose-rolling.png`、`mfstream_t2`）。
- 建模建议：嘴部做成分离的口腔壳体 + 形状键（shape key）控制张合，方便表情复用。

### 4. 手臂与手（2 只）
- 手臂细短、无肘部明确结构，光滑弯曲；末端为**橄榄棕色的小手**，3~4 根短圆手指（无拇指对握细节，剪影即可）。
- 颜色渐变：手腕处开始由黄渐变到深橄榄棕，指尖最深（像"脏了的手"），参考 `naiwa-standing.png`。
- 常见姿势：自然下垂、捧腹、背手、挥手。

### 5. 腿与脚（2 条）
- 腿短粗、微弓（外八站立）；大腿被肚皮遮住一部分。
- 脚：扁平大脚掌，**3 趾**，趾端圆钝，颜色与手相同往趾端渐变到深橄榄棕。
- 脚底平贴地面，作为模型的接地基准。

### 6. 尾巴
- 臀部后上方一个小钝圆锥凸起，长约 0.06H，无骨骼细节，随臀部整体运动即可。

## 四、色彩规范（实测自官方图）

| 部位 | 色值 | 备注 |
| --- | --- | --- |
| 身体主色（亮面） | `#F5C24B` ~ `#F8C850` | 金黄色 |
| 身体主色（暗面） | `#D89830` ~ `#E0A838` | 同色系加深，用于渐变 |
| 肚皮 | `#F6ECDB`（中性光）/ `#F1DAB9`（暖光） | 奶油色大椭圆色块 |
| 手/脚端部 | `#5B3E19` ~ `#61421A` | 深橄榄棕 |
| 眼睛虹膜 | `#7BA459` ~ `#81A468` | 黄绿色环 |
| 瞳孔/嘴缝线 | 接近 `#1A1A1A` | 纯黑 |
| 口腔内壁 | 深红棕 `#5C1F1F` 附近 | 大笑帧取样 |
| 牙齿 | `#F5F0E8` | 微暖白 |

肚皮色块形状：正面一个大椭圆，上缘在胸口（约 0.55H 高度），下缘接近两腿之间，左右约占躯干正面宽度的 75%。用顶点色或简单贴图即可，无需 UV 精细展开。

## 五、材质与渲染

- 整体：**哑光黏土/搪胶质感**——低粗糙度变化（roughness ≈ 0.5~0.6）、无纹理图案、轻微次表面散射感（可省略）。
- 手脚颜色渐变：推荐几何节点/顶点色沿手臂轴向插值，避免画贴图。
- 灯光友好：单色主体 + 柔和环境光即可出官方图效果；AR 端用轻量材质（URP/Lit 或 Simple Lit）。

## 七、Blender + GPT 工作流建议

1. **单位与尺度**：场景用米制；模型按真实 20cm 建好后再导出（Blender 里 0.2m），脚底中心为世界原点，+Y 为面朝方向（与 Unity 惯例一致需在导出 FBX 时确认轴向）。
2. **建模顺序**：躯干蛋形 → 调整头身比例 → 眼球嵌入 → 口腔壳体 → 四肢（直接从躯干拉出或独立球体合并）→ 尾尖。
3. **优先用形状键**做表情（嘴张合、闭眼），减少骨骼数量；骨骼只做：头根、脊柱一节、左右肩、左右髋、尾根，共 7 根左右即可满足待机/进食/走动。
4. **第一轮验收**只要求：站姿 + 进食低头两个动作，正面/侧面轮廓与参考图对照不超过明显偏差（见 AGENTS.md 资产流程）。
5. 给 GPT 的提示词可参考本简报第二、三、四节直接引用数值。
