# 奶蛙建模参考简报（供 GPT + Blender 使用）

> 整理日期：2026-09-08
> 用途：为"桌上有龙"AR 项目主角（奶蛙风格圆润生物）的三维建模提供统一参考。
> 使用方式：由助手直接调用 D:/blender.exe 与 Python/bpy，参考本文件和图片逐步制作、检查与导出。
> 2026-09-08 用户已确认：以 `milkyfrog_official/milkyfrog-hero.png` 的站立主视觉作为身体比例基准。
> 素材来源与版权说明见文末。

## 一、角色定位与风格

- 一只金黄色、体型极胖的直立小生物：小头、巨腹、短四肢，形象介于青蛙与恐龙幼崽之间。
- 整体气质：呆萌、慵懒、略带"抽象"喜感；表面光滑如黏土玩具/搪胶摆件，无毛发、无鳞片、无衣物。
- 参考体系说明：不同网站与同一目录中的图片都存在比例、视角和姿态差异，不能仅按网站来源分成两套严格统一的模型。
  - **主参考已确认**：`milkyfrog_official/milkyfrog-hero.png`，以站立主视觉的身体比例、腿长、腹部轮廓与五官位置为准。
  - **辅助参考**：`naiwa_meme/naiwa-standing.png` 补充站姿观察；吐舌、挥手、侧躺、打滚图和视频补充表情、动作，不逐项覆盖主图比例。
- 当前没有同一中性站姿的正交正面、侧面和背面图。背部、腹部厚度、尾根与隐藏的手脚结构需在灰模中补设计，再输出多视角复核；俯卧侧图不能直接当站立侧视图。

## 二、整体比例（按 AR 角色 20cm 总高设计）

以下以总高 H = 20 cm 为基准，作为初稿比例参考。现有图片带透视且姿态不一致，后续需按已确认的站立主图与灰模复核，不把这些数值当成精确三视图测量结果：

| 部位 | 比例 | 20cm 换算 |
| --- | --- | --- |
| 总高（站姿，头顶到脚底） | H | 20 cm |
| 头顶到下巴（头部含于躯干） | ≈ 0.30H | 6 cm |
| 身体最宽处（下腹）宽度 | ≈ 0.72H | 14.4 cm |
| 肚皮最大前后径 | ≈ 0.62H | 12.4 cm |
| 腿长（髋到脚底） | ≈ 0.28H | 5.6 cm |
| 手臂长（肩到指尖） | ≈ 0.30H | 6 cm |
| 脚长 | ≈ 0.24H | 4.8 cm |
| 眼球直径 | ≈ 0.055H | 1.1 cm |
| 尾巴尖凸起 | ≈ 0.06H | 1.2 cm |

要点：

- **没有脖子**：头部直接融入躯干，从头顶到尾尖是一条连续的弧线（侧视最明显，参考 `mf-pose-lying.png`）。
- 身体质心低，下腹最宽；正面肚皮几乎贴地感。站姿为两条短腿微外八支撑。
- 头部从正面看约占全身高度的 1/3，其中眼睛位于头的上半部、偏前侧。

## 三、分部位建模要点

### 1. 头与躯干（一体成型）
- 用一个 UV 球或经 Sculpt 简单塑形：整体呈**竖置蛋形/梨形**，上部收窄成头，下部膨大成腹。
- 背部弧线：从头顶向后下方平滑过渡到臀部，途中在臀部后上方留一个小圆锥凸起（尾尖，钝圆）。
- 正面：胸部到下腹为一个大弧面；肚皮色块区域见第四节。

### 2. 眼睛（2 颗）
- 半嵌入头部的圆球，默认睁眼时眼睑不突出；眼白不可见，动画所需眼睑另行设计。
- 结构：外圈黄绿色虹膜环 + 大黑色瞳孔 + 高光点。瞳孔极大，约占眼球可见面积的 60%。
- 位置：头顶部前侧，间距约一个眼球直径；从正面看双眼都朝前（略内聚的呆萌感）。
- 表情需要闭眼时，用**上眼睑（与身体同色的壳）下压遮住眼球**的方式实现（参考 `video_frames/mfstream_t2.png` 大笑帧），不要用贴图换脸。

### 3. 嘴
- 默认：一条细长的横向缝线（微弯、无唇部结构），位于头部下沿前方，宽度约为头部最大宽度的 60%。
- 大笑张开时：口腔内部深红色，**上颚一排白色小牙**（圆钝、不尖锐），可加粉红舌头；张口极大时嘴角几乎到头侧（参考 `mf-pose-rolling.png`、`mfstream_t2`）。
- 建模建议：嘴部做成分离的口腔壳体 + 形状键（shape key）控制张合，方便表情复用。

### 4. 手臂与手（2 只）
- 手臂细短、无肘部明确结构，光滑弯曲；末端为**橄榄棕色的小手**，3~4 根短圆手指（无拇指对握细节，剪影即可）。
- 颜色渐变：手腕处开始由黄渐变到深橄榄棕，指尖最深（像"脏了的手"），参考 `naiwa-standing.png`。
- 常见姿势：自然下垂、捧腹、背手、挥手。

### 5. 腿与脚（2 条）
- 腿短粗、微弓（外八站立）；大腿被肚皮遮住一部分。
- 脚：扁平大脚掌，**3 趾**，趾端圆钝，颜色与手相同往趾端渐变到深橄榄棕。
- 脚底平贴地面，作为模型的接地基准。

### 6. 尾巴
- 臀部后上方一个小钝圆锥凸起，长约 0.06H，无骨骼细节，随臀部整体运动即可。

## 五、材质与渲染

- 整体：**哑光黏土/搪胶质感**——低粗糙度变化（roughness ≈ 0.5~0.6）、无纹理图案、轻微次表面散射感（可省略）。
- 手脚颜色渐变：可用顶点色或贴图制作；导出时需烘焙为贴图，或在 Unity 中使用支持顶点色的材质。Blender 节点与材质效果不会通过 FBX 自动完整复现。
- 灯光与材质：单色主体配合柔和光照作为初稿起点。AR 端的材质随验证通过的渲染管线确定；若最终采用 URP，再考虑 Lit 或 Simple Lit。

## 七、Blender + GPT 工作流建议

1. **单位与尺度**：场景用米制，角色约 0.2m 作为起点，根节点以脚底中心为准。Blender 源文件约定 +Y 向前、+Z 向上；导入 Unity 后检查 +Z 向前、+Y 向上，按实际导出结果校验轴向转换。
2. **建模顺序**：躯干蛋形 → 调整头身比例 → 眼球嵌入 → 口腔壳体 → 四肢（直接从躯干拉出或独立球体合并）→ 尾尖。
3. **骨骼与表情**：嘴张合、闭眼可用形状键；骨骼覆盖根节点、身体、头与四肢，实际关节数量由动作和变形需求决定，不预先认定 7 根就足以完成走动。先检查嘴眼拓扑、权重及肩髋等连接处。
4. **第一轮验收**：中性站姿、可循环的待机 `Idle`、一次性的进食 `Eat`，以及正侧背与斜视轮廓。随后检查 FBX 导出与 Unity Generic 动画导入（见 AGENTS.md 资产流程）。
5. 直接由助手通过 Python/bpy 建模并保存可编辑源文件，输出预览后逐轮调整；第二、三、四节为参考，不代替主图对照和实际变形检查。
