# Configs — 可调参数

| 文件 | 类型 | 说明 |
| --- | --- | --- |
| `PetBehaviorConfig.asset` | ScriptableObject | **运行时真正读取的配置**。由菜单 **桌上有龙 / 2. 只生成默认配置资产** 创建。 |
| `pet_config.template.json` | 模板 / 说明 | 字段说明与默认值清单，供人工核对与评审。**不是运行时数据源。** |

为什么要有两个文件：ScriptableObject 是二进制 / YAML 资产，**必须由编辑器生成**，
在 Unity 未安装时无法写出来；而参数本身需要被评审和讨论。
因此用 JSON 记录"应该是什么值"，用 `.asset` 承载"实际是什么值"，
并在 `pet_config.template.json` 顶部注明它不是运行时来源，避免两份配置互相矛盾。

## 归属规则

**所有阈值都属于这里，不属于代码。** 出现以下情况说明放错了位置：

- 同一个数值（例如投喂距离）在多个脚本里各写一遍；
- 改一个手感参数需要动 `.cs` 文件；
- 界面上显示的阈值与判定用的阈值不是同一个来源。

## 参数清单与状态

| 参数 | 默认值 | 状态 |
| --- | --- | --- |
| 饥饿 / 开心 / 精力 初始值 | 0.30 / 0.60 / 0.85 | 设计初值 |
| 饥饿 / 开心 / 精力 每秒变化 | +0.0035 / −0.0015 / −0.0010 | 饥饿上升，开心与精力下降 |
| 离线补算上限 `MaxOfflineSeconds` | 12 小时 | 设计初值 |
| 饥饿阈值 `HungryThreshold` | 0.65 | 设计初值 |
| 困倦阈值 `SleepyThreshold` | 0.25 | 设计初值 |
| 投喂最大水平距离 | 0.10 m | **待真机调整** |
| 投喂最大高度差 | 0.06 m | **待真机调整** |
| 投喂所需停留时长 | 0.6 s | **待真机调整** |
| 投喂冷却 | 4.0 s | **待真机调整** |
| 再进入距离 `ReArmDistance` | 0.16 m | **待真机调整** |
| 位姿过期阈值 `staleSeconds` | 0.35 s | **待真机调整** |
| 动画过渡时间 | 0.15 s | 设计初值 |
| 进食结算（饥饿度） | −0.45 | 设计初值 |

**这些数值一个都还没有经过真机体验验证。** 调整后请同步更新 `pet_config.template.json`，
保持两份记录一致。

默认投喂参数由 `EatConfig.Default` 初始化。单次行为必须非循环且具有有限正时长；默认行为必须为已具备动画的循环行为，不能设为自动重复的 Eating。新建存档使用配置初值，已有有效存档优先恢复。
