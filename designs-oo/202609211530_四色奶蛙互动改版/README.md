# 四色奶蛙互动改版：设计入口

本目录记录 2026-09-21 提出的玩法改版，阶段为**计划与架构设计**。方案中的新职责和实施阶段不代表业务代码已改造、Vuforia 新数据库已导入或新动作已制作。

2026-09-21后续进展：文档与资产映射已收口，现役状态见 [四色资产映射](../../Docs/四色奶蛙资产映射.md) 和 [范围v0.3](../../Docs/交互与皮肤扩展设计.md)。design_v1中的“本轮未同步旧文档”描述的是设计时点；具体参数/动作仍待定，独立审查仍未完成。

## 用户已确定的方向

- 从单一黄色奶蛙扩展为四色奶蛙。
- 开心值与好感度合并为一个数值，统一称“开心值”。
- 点击、双击等触屏交互提高对应奶蛙的开心值。
- 各色奶蛙在100%开心值时触发自己的专属动作。
- 删除食物卡玩法。
- 同屏不同奶蛙靠近时共同大笑。
- 最终支持四色四只同屏，先完成双宠竖切验证，再进行四宠跟踪与性能实测。
