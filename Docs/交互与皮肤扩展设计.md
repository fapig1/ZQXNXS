# 交互与皮肤扩展设计

> v0.3 · 2026-09-21（2026-10-27 状态补注）。用户确认由单宠换肤升级为四色独立奶蛙互动。文档和资产映射已收口；源码已完成 P2 多宠竖切（`TargetId`/`PetId` 契约、`PetSession`+`PetRuntime` 逐宠运行、食物链退出、存档 schema 2）与 P3 手势与满值闭环（每宠独立的单击/双击识别、四色定稿参数、满值周期与正式专属片段、TouchReact 与开心条，EditMode 161/161），P4 接近组共同大笑（EditMode 223/223）与 P5 二维嘴眼贴片（EditMode 231/231）。待做的是特效、音效与四宠真机/UI 整合；四宠场景未真机测试。旧v0.2完整保留在 [历史文档](交互与皮肤扩展设计_v0.2_历史.md)。

## 1. 用户已确认

- 四款为classic暖黄、calm湖蓝、rage朱红、divine紫，卡面与外观设计已经存在。
- 开心值与好感度合并为“开心值”；每只独立记录，点击/双击提高对应角色数值。
- 每款在100%开心值时触发一个专属动作。
- 删除食物卡玩法；同屏不同奶蛙靠近时一起大笑。
- 最终四色四只同屏，先双宠竖切验证；不能把双宠阶段当最终上限。

主线：**摆卡召唤 → 触屏积累开心 → 满值性格演出 → 靠近共同大笑 → 本地保存**。照片、追球、反应解锁未被用户取消；追球延后及解锁简化仍为方案建议。

## 2. 范围变更说明

| 旧v0.2/开题基线 | 当前目标 |

饥饿数值与投喂依赖已于 2026-10-27 随玩法退出运行；独立精力条未做，开心值自然衰减已按用户 2026-10-27 定稿关闭（`DecayPerSecond=0`，代码路径保留）。旧Eat动作保留作冻结资产，不再进入新版行为表。

## 3. 架构决定与参数

保留七层、单AppRoot装配；泛化目标ID，创建逐宠Runtime，输入绑定PetId，增加跨宠演出协调器，共用相机/输入采集/存档写入。2026-10-27：`TargetId`/`PetId`、`PetSession`+`PetRuntime`、存档 v2 已实现；跨宠演出协调器仍待做。AR只依赖Core，Presentation不依赖Pet；阈值与形象→行为映射进入配置。

详细契约、迁移面与P0～P7计划见 [架构设计v1](../designs-oo/202609211530_四色奶蛙互动改版/design_v1.md)。该稿未经独立代理审查。手势与满值参数已于 2026-10-27 定稿并实现：每宠一个0.28s双击窗口、四色单击/双击加分、满值回落与重新武装阈值、专属冷却与时长均进入 `PetBehaviorConfig.asset`（数值见下方建议稿 §3）。共同大笑不加分、相邻链传播仍为设计建议，未实现。

动作候选为classic得意三连晃、calm佛系点头、rage兴奋怒吼、divine神格觉醒；另加共享大笑。2026-09-22已按表情包素材审查细化逐色演出与差异化参数（统一100%触发，四色加分/回落/重装/冷却/时长不同），动作选型已定候选A，共享大笑按用户要求夸张化制作（身体后弯至90°可接受，须回读验证不破面），见 [专属动作与阈值参数建议 v0.1](../designs-oo/202609211530_四色奶蛙互动改版/专属动作与阈值参数建议_v0.1.md)；差异化数值已于 2026-10-27 由用户按该稿 §3 定稿。旧Happy取消与新增共享大笑是两个不同事项。
