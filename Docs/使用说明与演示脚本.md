# 使用说明与演示脚本

更新：2026-10-30。适用 `02_Main` 四色多宠版本（含 2026-10-30 两轮真机问题修复，Unity EditMode 273/273，`ARPet/TestResults-RealDevice2-20261030.xml`）。2026-10-30 首轮真机已测单卡、点按、满值专属、丢失恢复与语音（见 [真机测试问题记录](真机测试_20261030_问题记录.md)）；本版修复后的共同大笑、上半身点按、首次授权麦克风与横屏**尚未复测**，下文这几项仍是按代码写的预期。

## 1. 玩家使用说明

**准备**：Android 10 以上手机（首测机型 iQOO Z9 Turbo / Android 15），安装 `ARPet-phone-test.apk`；四张角色卡按 100% 哑光打印，有效图案约 66×94mm。光线均匀、避免卡面反光。

| 想做的事 | 怎么做 | 会看到什么 |
| --- | --- | --- |
| 唤出奶蛙 | 打开 App，允许相机权限；把一张角色卡放在桌上，手机在 20～40cm 外对准整张卡 | 卡上出现对应颜色的奶蛙（暖黄 / 湖蓝 / 朱红 / 紫），面板列表里它显示"在场" |
| 喊口令 | 按住屏幕底部"按住说话"，喊"安迪""嘎嘎爹拉筛""雷霆大笑"或"欧拉"，松开 | 画面里所有奶蛙用同一句配音回应：安迪→挥手打招呼，嘎嘎爹拉筛→小跳一下 + o 嘴，雷霆大笑→后仰大笑，欧拉→叉腰怒吼；每只各加一次单击的开心值。第一次会请求麦克风权限；同一只 3 秒内只回应一次 |
| 逗它 | 单击奶蛙（脚到头顶任何位置都可以） | 奶蛙做一次 0.7s 的反应动作，嘴变成 o 形；开心值增加（四色加分不同） |
| 更开心 | 快速双击（两次点按间隔 < 0.28s） | 只算一次双击奖励，不会按两次单击算 |
| 满值专属演出 | 把开心值点到 100% | 播一次该颜色的专属动作与招牌表情：暖黄打招呼 + 眯眼微笑，湖蓝合十点头 + 闭眼，朱红叉腰怒吼 + 怒眼，紫色展翅 + 纯白发光眼。之后开心值回落，冷却结束、重新点满才会再播 |
| 共同大笑 | 把两张卡并排放（间距约 15cm 以内、朝向大致一致、平放在同一桌面），停一会儿（约 0.6 秒）。先放一张、再把第二张直接放到旁边也可以 | 两只同时大笑（眯眼大笑嘴）；三四只靠在一起时整组一起笑，同一只不会重复笑 |
| 结束大笑 / 再来一次 | 把其中一张卡拿出画面 2 秒以上，再放回旁边一个稍有不同的位置（和原来差 3cm 以上）；或两卡都在画面里时拉开到 23cm 以外再靠近 | 拉开或拿走任一张，整组停止；贴着不动、或卡原地短暂识别不到又回来，都不会重复笑。每只有 5 秒冷却 |
| 横屏 | 把手机横过来 | 画面与界面跟着旋转；横屏视野更宽，两张卡更容易同时入镜。面板移到左上角 |
| 卡片被挡住 | 手或物体挡住卡，或卡移出画面 | 该奶蛙立即隐藏、不能被点；其他奶蛙不受影响。放回后原样出现，开心值不变 |
| 退出 / 切后台 | 按 Home 或切换应用 | 进度自动保存；回来后继续，不重置 |

面板文字：上方是选中奶蛙的跟踪提示与操作提示；中间是当前动作（Idle / Busy / Happy! / Laughing together! / Full - tap to celebrate）与开心值；下方列出四只奶蛙的颜色、在场状态与开心值百分比；右下角是帧率。

**已知限制**：嘴眼是贴在脸前的二维图，只在动作切换时换，不随眼睑/嘴的骨骼动作变形；特效未做，音效只有四段口令配音；语音只认四句口令，说别的不会回应；"触屏"是点屏幕上的奶蛙，不是手真的碰到卡；只支持识别这四张卡，不识别其他物体，也不做真实遮挡。

## 2. 演示脚本（约 4 分钟）

| 时间 | 演示动作 | 讲解要点 | 验证点 |
| --- | --- | --- | --- |
| 0:00 | 打开 App，放一张暖黄卡 | 图像跟踪：Vuforia 识别实体卡，角色锚定在卡上 | 角色出现且贴在卡面，不漂 |
| 0:30 | 单击、双击奶蛙 | 每只独立开心值；双击只结算一次；输入层与行为层分离 | 反应动作与 o 嘴；开心值变化 |
| 1:10 | 继续点到 100% | 行为状态驱动：满值周期（触发→回落→冷却→重新武装） | 专属打招呼 + 眯眼微笑只播一次 |
| 1:50 | 放上湖蓝卡，两卡并排 | 多目标跟踪 + 接近规则（距离迟滞、高差、夹角、停留）+ 组协调 | 两只同帧大笑 |
| 2:30 | 拿走湖蓝卡 | 逐宠丢失：整组取消、该宠隐藏、另一只继续 | 暖黄继续 Idle |
| 3:00 | 放回湖蓝卡，再放朱红、紫卡 | 四宠同屏；丢失恢复不重置数值 | 四只各自显示，列表四行 |
| 3:20 | 四只在场时按住说话喊"欧拉"，再喊"雷霆大笑" | 离线关键词识别（sherpa-onnx，无网络），一句口令所有在场宠物同时回应，加分仍由行为层统一结算 | 四只同时怒吼 / 大笑并出声 |
| 3:40 | 切后台再回来 | 本地存档 schema 2，按宠物 ID 保存 | 开心值保持 |

备用：若现场光线导致识别不稳，先展示 `03_ExclusiveAnimationPreview`（编辑器内四段专属动作）与 Unity EditMode 测试报告，再说明真机限制。
