## 使用与后续

菜单“桌上有龙 / 动画 / 接入四色专属动作”配置真实FBX片段和 `PetExclusiveAnimations.asset`；“创建四色专属预览场景”生成 `03_ExclusiveAnimationPreview.unity`，四个按钮独立播放对应角色并回到Idle。开发预览没有开心值奖励或Animation Event结算。

后续需先补齐rage/divine开放轮廓与classic收势，再制作嘴眼表现。动作身份沿用已定稿ID；加分、冷却、回落参数仍未定稿。共享大笑独立待制作。场景中四色开发预览不证明四目标AR、多宠业务或满值触发已经实现。

本轮额外做了肩部双轴与肘部旋转组合扫描，数值见 `ExclusiveActions/arm_pose_diagnostics.json`。满足边长限制的候选未提供可证明张臂语义改善的视觉证据，因此没有替换现有动作或宣称完整候选A已完成。制作管线现已禁止直接覆盖已有制作副本、阻止重复平滑，推广要求数值/旧动作回归匹配当前源及FBX哈希；视觉文件只允许标注开发预览，完整演出验收仍为false。
