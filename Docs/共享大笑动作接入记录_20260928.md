## 节奏

| 时刻(s) | 阶段 | 骨骼动作 |
|---|---|---|
| 0–0.30 | 预备 | 前收 8°，躯干略压扁，开始眯眼 |
| 0.30–0.74 | 第一波 | 后弯 65°，双臂外甩 22°，躯干纵向拉伸 10%，嘴张到上限 |
| 0.74–1.22 | 回弹 | 回落到后弯约 22°，胸部扭转回摆 |
| 1.22–1.48 | 捧腹 | 前弯 35°，躯干压扁 15%，双臂交替拍肚 ±14° |
| 1.48–2.00 | 第二波 | 后弯 105°（最深），扭转 10°，甩臂 10° |
| 2.00–2.40 | 收势 | 回到静止；眯眼保持到 2.22s 再睁开 |

整段叠加笑抖效果：胸部左右抖 6°（8Hz），俯仰抽动 3°（5.5Hz），尾巴甩 18°，嘴张合随抽动起伏。弯曲按 Spine 20%、Chest 25%、Head 55% 分配，Pelvis 不参与，所以双脚完全不动。

## 与设计要求的差异

- **没有重新绑定骨骼**。2026-09-28 的探测（见 [数值探测](AssetReview/20260928_大笑动作探测/findings_数值探测.md)）发现，躯干权重平滑反而会让后弯出现穿插；只要调整弯曲在各骨骼上的分配，后弯到 110° 也不会破面。网格、权重、静止骨架和原有 9 段 Action 经指纹校验，没有任何变化。
- **手臂外展上限约 25°**。手臂和肚皮属于同一个网格壳，有 3,601 个混合权重顶点，外展超过 40° 后腹部拉伸会超限。捧头、高举双手这类动作要先修手臂/腹部权重，也就是新开一个 shape_revision，本轮没做。（2026-09-29 已由 [手臂分离修订](手臂分离修订记录_20260929.md) 解除：手臂改为独立外壳；本段曲线未改，只在新网格上重新验证，拉伸上限放宽到 2.25。）
- **最深后仰时，正面看不到脸**。这是后仰的物理结果；侧面和斜前方能读出“笑到后仰”。
- 骨骼嘴已经张到上限。横椭圆大嘴、开心眯弧眼、divine 白眼变体都要靠二维贴图实现，本轮未做。
- 连续帧顶点位移最大约 26mm/帧。通用的 10mm/帧阈值是为平缓动作设的，这里在脚本和报告中明确改为 35mm。FBX 回读额外采样了最快的几帧。
