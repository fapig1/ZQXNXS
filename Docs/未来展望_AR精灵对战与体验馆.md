# 未来展望：AR 精灵对战与沉浸式体验馆

> 性质：**展望规划，本轮不实现**（开发者 2026-10-27 提出，见 `开发者的想法.md`）。只用于最终报告与答辩 PPT 的"未来工作"部分。当前交付范围仍以[交互与皮肤扩展设计](交互与皮肤扩展设计.md)为准。文中数字是设想，不是测试结果。

## 1. 一句话愿景

从"桌上养一只奶蛙"扩展到"收集、培育、对战"：玩家手里的实体卡就是精灵，和 NPC 或其他玩家用卡片对战，赢了可以收服对方的精灵；线下再做一座 AR 体验馆，戴上 AR 眼镜走进场地，一路挑战 NPC，最终击败 Boss。

## 2. 与现有系统的衔接

现有成果直接复用，扩展是在上面加层，而不是重做：

| 现有能力（已实现） | 在展望里的用途 |
| --- | --- |
| Vuforia 多卡识别，四卡同屏，稳定 `PetId` / `TargetId` | 一张卡 = 一只精灵的身份；对战时双方各自出卡 |
| 每只宠物独立的开心值与行为状态机 | 扩展为"亲密度"，影响对战中的出手率、暴击等 |
| 四色专属动作 + 二维表情 + 共同大笑 | 技能动画、胜利/失败表情、合体技的基础 |
| 接近规则与组协调（两卡靠近触发） | 两卡对面放置 = 进入对战；三卡靠近 = 组队 |
| 本地存档 schema 2（按 ID 版本化） | 扩展为精灵图鉴、等级、收服记录 |

## 3. 精灵形态与成长

| 形态 | 说明 | 获得方式（设想） |
| --- | --- | --- |
| 奶蛋 | 初始形态，不能战斗；需要陪伴（点按、说话）积累孵化值 | 体验馆入口发放 / 新手卡 |
| 奶蛙 | 现在的四色形态：暖黄（得意）、湖蓝（佛系）、朱红（怒吼）、紫（神格） | 奶蛋孵化，颜色由孵化期互动方式决定 |
| 进化形态 | 每色一条进化线，外观与技能强化 | 亲密度满 + 对战胜场达标 |
| 稀有形态 | 例如"金色奶蛙""暗影奶蛙" | 只能通过击败特定 NPC / Boss 收服 |

四色可自然对应属性克制，形成"石头剪刀布"：**朱红（火/怒）→ 紫（神/灵）→ 湖蓝（水/静）→ 朱红**，暖黄为平衡型，不被克也不克别人。

## 4. 卡牌对战规则（草案）

- **开战**：双方各把一张精灵卡放到桌面上、相向放置；系统识别到两卡正对且距离合适，就进入对战（沿用现有接近规则）。
- **回合**：每回合各选一个技能（屏幕按钮，或在 AR 眼镜里看着目标做手势/喊技能名）。技能三类：攻击、防守、特技（专属动作 = 大招）。
- **数值**：生命、攻击、速度三项，加上属性克制倍率；亲密度提高暴击率与"不听话"的抵抗率。
- **胜负与收服**：把对方生命打到 0 即胜。对 NPC 获胜后有概率收服其精灵，收服成功会生成一张"数字卡"，可在体验馆打印成实体卡带走。
- **公平性**：玩家之间对战默认"友谊赛"，不夺取对方精灵；只有 NPC 和 Boss 可以被收服，避免真人之间的损失纠纷。

## 5. 沉浸式 AR 体验馆

### 5.1 动线

| 区域 | 内容 | 时长（设想） |
| --- | --- | --- |
| ① 迎宾区 | 领取 AR 眼镜与初始奶蛋卡，观看 1 分钟引导动画 | 5 min |
| ② 孵化花园 | 陪伴奶蛋（点按、说"你好"），孵化出第一只奶蛙 | 10 min |
| ③ 训练道馆 ×3 | 每个道馆一位 NPC 训练师，各自擅长一种颜色；赢了获得徽章与收服机会 | 每馆 8～10 min |
| ④ 野外草丛 | 场地里隐藏着可识别的标记，靠近会刷出野生精灵，可战斗收服 | 自由探索 |
| ⑤ Boss 殿堂 | 集齐三枚徽章后开放，最终 Boss "奶蛙王"多阶段战斗，可组队 | 15 min |
| ⑥ 纪念区 | 打印收服的精灵卡、生成本次冒险的回顾短视频 | 5 min |

### 5.2 硬件与技术

| 项 | 设想 |
| --- | --- |
| 显示 | 光学透视 AR 眼镜（或手机 / 平板作为低成本方案）；场地内固定标记 + 空间锚点定位 |
| 识别 | 实体卡继续用图像跟踪；场景用空间锚点（场地预先扫描建图） |
| 交互 | 手势识别、语音指令（喊技能名）、实体卡出牌 |
| NPC | 真人演员 + AR 精灵，或纯虚拟 NPC；Boss 战加入灯光、音效联动 |
| 后台 | 场馆服务器保存玩家进度、排队、对战匹配；玩家离馆后数据可同步回手机 App |

### 5.3 落地路线（分阶段）

| 阶段 | 目标 |
| --- | --- |
| 阶段一（当前课程项目） | 单机桌宠：四色奶蛙、触屏互动、满值演出、接近共同大笑 ✅；语音互动（下一步） |
| 阶段二 | 手机上的双人卡牌对战：两部手机同时识别、局域网同步回合 |
| 阶段三 | 奶蛋孵化与进化线、图鉴与收服、NPC 对战 AI |
| 阶段四 | 体验馆原型：小场地 + 3 个道馆 + Boss，先用平板代替 AR 眼镜试运营 |
| 阶段五 | AR 眼镜版正式体验馆，加入多人组队 Boss 战 |

## 6. 主要风险

| 风险 | 应对 |
| --- | --- |
| AR 眼镜成本高、佩戴时长受限 | 先用平板验证玩法；单次体验控制在 60 分钟内 |
| 多人同场的识别与同步延迟 | 回合制对战对延迟不敏感；同步只传回合指令，不传画面 |
| 与已有 IP 玩法相似 | 突出"实体卡 + 桌面 AR + 奶蛙原创形象"，不使用他人角色与名称 |
| 收服机制引发纠纷 | 真人之间只做友谊赛，收服仅限 NPC / Boss |
| 内容制作量大（形态 × 技能 × 动画） | 沿用本项目的"共享骨架 + 换贴图 + 二维表情"管线，降低每只精灵的制作成本 |

## 7. PPT 建议页面（约 5 页）

1. **愿景**：从桌宠到 AR 精灵对战（一张主视觉：桌上两张卡、两只奶蛙对峙）。
2. **形态与成长**：奶蛋 → 四色奶蛙 → 进化形态，配属性克制环。
3. **对战玩法**：开战方式、回合、技能、胜负与收服（流程图）。
4. **AR 体验馆**：场馆平面动线图（迎宾 → 孵化 → 道馆 → 野外 → Boss → 纪念）。
5. **路线图与风险**：五阶段时间轴 + 三条主要风险。
