## 改了什么

- **躯干**：用 `build_pet01.py` 的生成器重建身体、腿、尾巴和眼睛，只是不带手臂，然后绑回原骨架。和旧顶点重合的点直接拷贝权重；原来被手臂盖住的那条带只重算躯干骨骼的份额。面部和眼睛与上一版的差异在 1µm 以内（实测 5.1e-7m）。
- **手臂**：每条手臂是一个独立的闭合外壳（肩球半径 13.5mm、上臂、前臂、手掌和手指），每条约 2000 三角面。权重在肘部 ±16mm、腕部 ±4mm 的范围内过渡。外壳和躯干不相连，这是设计：肩部球关节在侧视时会露出轮廓，但不会裂开。
- **classic_proud（打招呼，2.0s）**：`.L` 臂（蛙的右手）举到头侧上方，上臂约 33°、前臂接近竖直，挥手两次，摆幅 ±18°，手腕晚约 2 帧跟随。身体朝挥手侧转 12°，头部侧倾并点头，另一只手留在肚子上。
- **divine_awaken（天使展翅，2.5s）**：双臂水平展开，后掠约 29°，手腕上扬约 12°。胸部后仰 15°，头部上仰。保持段扇翅一次，收回时沿身体两侧落下。
- 另外 8 段 Action 的曲线没有改动，校验项是 `kept_action_curves_unchanged`；稳定 ID 不变。

## 2026-10-26 右肩外露检查（搁置）

- **现象**：静止时蛙右肩（`.R`）肩球与躯干交界的上-前段可见一条暗色楔形缝/薄片，左肩对应位置干净；真机截图在 classic 与 rage 两种蛙色、相反光照、不同相机偏置下重复出现，指向几何而非光照或贴图（`device_review.md`）。
- **原因**：肩球球心位于躯干表面，球与躯干形成约 80° 的接缝；外壳边缘与躯干面近乎相切，亚毫米级壳位差异就会让薄唇只在右侧露出。离线 blend 与 FBX 表现一致，排除导出新增。
- **判定**：填补该接缝不可行（需改动已授权的形体/权重与肩部轮廓，且不能保证不破面）。用户 2026-10-26 决定先不管，作为已知外观缺口保留。
