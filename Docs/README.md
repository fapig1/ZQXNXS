## 按变更类型同步

| 发生的变化 | 必须检查的文档/证据 |
| --- | --- |
| 功能范围、已确认决策 | 范围文档、架构迁移说明、根 README/AGENTS 摘要；新建议标“提案” |
| 卡面、贴图、目标名/尺寸/评级/数据库 | 资产映射与 JSON、StreamingAssets README、SETUP；核对实际 XML/DAT、跟踪数和生成/构建工具；评级须有门户记录 |
| 模型、Action、导出与接线 | 冻结说明、源/Unity manifest、源/模型/Animations/Prefabs README、映射；制作通过与 Animator 能力启用分开 |
| 工具链、API、渲染、构建方式 | 环境锁定表、技术栈、SETUP、ARPet README、Plugins/Android README；与 Packages/ProjectSettings/ProjectSetup 核对 |
| 多宠、手势、数值、存档、平台功能 | 架构状态表、Scripts/Configs/Scenes 等目录 README、工程入口、对应验证证据 |
| 测试或真机进展 | 原始结果、执行日期/设备/条件/范围、现役短摘要；不把文档检查写成业务测试 |

正文、表格、步骤和待办均需检查，不能只在页首追加更新。已提交材料和不可变历史通过导航注明边界，不批量替换旧文中的“食物”“单宠”字样。

文档检查包括本地链接、相关 JSON 解析/唯一键、资产路径/尺寸/哈希、与配置和源码的关键声明对照、`git diff --check`。本地路径存在不保证 clone 后可用：本地 Vuforia tgz、Archive 和测试产物需按 SETUP/冻结说明处理。
