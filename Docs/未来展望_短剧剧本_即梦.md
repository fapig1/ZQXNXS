# 《桌上有龙：奶蛙大冒险》短剧剧本（即梦短剧 Agent 用）

> 性质：答辩 PPT / 报告"未来展望"用的**概念短片**，不是实机画面，片头片尾须注明"概念演示"。玩法依据见[未来展望：AR 精灵对战与体验馆](未来展望_AR精灵对战与体验馆.md)。时长约 2 分钟，16:9，16 个镜头。

## 1. 使用步骤

1. **先建角色**：在即梦里用四张立绘创建角色参考（主体参考 / 角色库）：
   `Docs/AssetReview/20260919_卡面基准形象/out/role_classic.png`、`role_calm.png`、`role_rage.png`、`role_divine.png`。
   不要用塔罗卡面原图当参考，卡面上的边框、盔甲、法袍、马会被照搬进视频。
2. **整段粘贴第 2 节**给短剧 Agent，让它拆分镜、生成画面。
3. **哪一镜走样就单独重做**：用第 4 节对应镜头的提示词，选图生视频，首帧挂角色图。
4. **剪映合成**：加字幕、配乐、音效；片头片尾打上"概念演示，非实机画面"。

## 2. 粘贴给短剧 Agent 的完整输入

```text
请为我制作一部约 2 分钟的 3D 动画短片，16:9，共 6 场、16 个镜头，每镜 5～10 秒。

【片名】桌上有龙：奶蛙大冒险
【一句话故事】大学生小禾走进一座 AR 精灵体验馆，戴上 AR 眼镜，孵化出第一只奶蛙，一路挑战三座道馆、收服伙伴，最后四只奶蛙用"共同大笑"打动了巨大的奶蛙王。
【基调】温暖、可爱、热血但不暴力。对战像游戏表演，没有受伤、流血和恐怖画面。

【画风（每个镜头都必须一致）】3D 软黏土质感 Q 版动画，皮克斯式明亮暖光，柔和体积光，浅景深，色彩饱和但干净。画面里不出现任何文字、边框和水印。

【角色设定（四只奶蛙是同一种生物、同一体型，只有颜色和气质不同）】
共同外形：圆润矮胖的水滴形小青蛙，头和身体连成一体、没有脖子；身体正面有一块很大的竖椭圆米白色肚皮；头顶两侧两颗凸起的大圆眼，绿色虹膜、黑色瞳孔；嘴是一条细短线；粗短圆柱手脚，手是圆拳头、不分手指；哑光软胶皮肤，没有花纹斑点；身高约 20 厘米，像桌上的小玩偶。
· 小黄（暖黄奶蛙）：奶油暖黄色，憨喜爱笑，招牌动作是挺胸挥手打招呼，技能带金色星星光点。
· 小蓝（湖蓝奶蛙）：湖水蓝色，安静佛系，招牌动作是双手合十闭眼点头，技能是淡蓝色水波涟漪护盾。
· 小红（朱红奶蛙）：朱红色，火爆冲动，招牌动作是叉腰后仰张嘴怒吼、全身发抖，技能是橙色火花冲击环。怒吼时嘴角向下，不是笑。
· 小紫（紫色奶蛙）：薰衣草紫色，庄严高冷，招牌动作是双臂水平展开、双眼变成纯白发光，技能是紫金色光柱。
· 奶蛋：鹅蛋大小，奶油白蛋壳带浅黄色圆点，会左右摇晃。
· 奶蛙王（最终 Boss）：约 3 米高的巨大奶蛙，深金色皮肤，米白大肚皮，头戴金色王冠、披红色短披风；威严但憨态可掬，不吓人。
· 小禾（玩家）：约 19 岁的大学生，齐肩短发，浅灰连帽卫衣、牛仔裤、帆布包，戴一副镜框泛淡蓝光的 AR 眼镜。
· 三位道馆训练师：蓝道馆的阿澜（穿浅蓝练功服的温和中年女士）、红道馆的阿焰（穿红色运动服的活泼少年）、紫神殿的星璃（披紫色星纹斗篷的少女）。

【分场剧情】
第1场 入场（约15秒）：明亮现代的室内 AR 体验馆入口，工作人员递给小禾一副 AR 眼镜和一张画着奶蛋的卡片。小禾戴上眼镜，眼前的空间浮现出淡蓝色的全息光点和路标。
第2场 孵化花园（约20秒）：小禾把卡片放在一张木桌上，卡片上方浮现出奶蛋。小禾轻声说"你好"，奶蛋晃了晃，蛋壳裂开，小黄探出头眯眼笑，"呱～"一声跳出来挥手打招呼，头顶飘起一串粉色爱心。
第3场 湖蓝道馆（约25秒）：竹木风格的安静道馆，阿澜把卡片放在对面，小蓝出现。两只奶蛙在桌面上对峙。小蓝双手合十闭眼点头，身前展开蓝色水波护盾；小黄挺胸挥手，金色星星光点撞上护盾，绽放成一片星光。小蓝睁开眼被逗笑，化成一张发光的卡片飞进小禾手里。
第4场 朱红道馆与紫色神殿（约20秒，快节奏剪辑）：火山熔岩风格的道馆里，小红叉腰后仰怒吼，橙色火花冲击环向四周扩散，最后它不服气地跺脚，又被小黄拍拍肩，加入队伍。紫色星空神殿里，小紫双臂水平展开、双眼变成纯白发光，一道紫金光柱冲天，它高冷地点头加入。小禾手里集齐三枚发光徽章。
第5场 Boss 殿堂（约30秒）：巨大的金色殿堂，奶蛙王从光芒中现身，跺脚让地面震动，四只奶蛙被震得一晃。四只奶蛙互相看看，靠在一起，同时后仰哈哈大笑，彩虹色的笑声音波一圈圈扩散。奶蛙王愣住，忍不住也跟着大笑，最后摘下王冠，轻轻放在小禾手心。
第6场 纪念区（约10秒）：小禾站在打印机旁，拿起四张刚打印好的实体奶蛙卡片，四只小奶蛙在卡片上蹦跳。镜头拉远，暖色光晕中结束。

【声音】轻快的电子童趣配乐，Boss 场切换为恢弘但可爱的管弦乐；奶蛙只发出"呱～"等叫声，不说人话；小禾只说一句"你好"。
【必须避免】写实恐怖、流血、武器伤害、多余的手指或肢体、奶蛙长出牙齿或眉毛（小红怒吼的张嘴除外）、画面文字与塔罗牌边框、角色颜色在镜头间变化。
```

## 5. 一致性与排错

| 问题 | 处理 |
| --- | --- |
| 奶蛙长出手指、脖子、牙齿或眉毛 | 在提示词里重复"手是圆拳头不分手指，没有脖子"；单镜重做时挂角色图 |
| 颜色在镜头间漂移（小蓝偏绿、小紫偏粉） | 镜头里点名颜色，例如"湖水蓝色"；同一场尽量用同一张首帧连续生成 |
| 四只同框时数量或颜色错乱 | 先用文生图生成一张"四只并排"的静帧，作首帧做图生视频 |
| 小红怒吼像在笑 | 加"嘴角向下、愤怒的大吼"；不行就改成背影加火花 |
| 小禾的长相在镜头间变化 | 先生成一张小禾全身定妆图存为角色，后续镜头都引用它 |
| 出现塔罗边框或卡面服饰 | 换成立绘 `role_*.png` 做参考，不要用定稿卡面 |
