## 风格结论（RWS vs 马赛）

- **马赛（Jean Dodal 1701）平面木刻风更适合奶蛙萌系改编**：头大身圆、大色块平涂、粗黑轮廓，与奶蛙梗图上色语言一致；三张构图互异，利于 Vuforia 两两区分。
- **RWS 写实线描的灰度特征更富**，"居中人物 + 大面积纯色背景 + 黑轮廓线 + 底部窄细节带"版式天然达标 Vuforia 灰度识别。
- **建议路线**：以 RWS 的构图骨架（推荐组合表）为画布基准，用马赛式平涂 + 粗描边上色画蛙；通用注意事项：避免大面积等值低对比色块（黄底/白袍/灰柱是主要扣分项），主特征集中在人物与前景物件带。
- 改编稿仍需 Target Manager 星级 ≥3（争 4–5）与两两交叉干扰真机评分验证，此为既有硬步骤。

# 塔罗卡面参考 · 视觉审查记录

日期：2026-09-20。对象为 1909 年 Rider-Waite-Smith 公版扫描（Pamela Colman Smith 绘），仅作卡面构图与配色艺术参考研究。

## 1. 圣杯四（Cups 04）→ 对应"01_蓝_平静_侧身慵懒"

- 主体与姿态：人物盘腿坐于树下草坡，双臂交叠抱胸、垂目沉思，姿态收敛内省，与"侧身慵懒/平静"情绪高度贴合；左下三只圣杯排列，云中一手递出第四只圣杯，人物不予理会。
- 主色调：大面积灰蓝天空 + 黄绿色草地，人物衣饰红/灰绿点缀，整体低饱和、安静谧。
- 细节密度：中等偏低——背景是简洁色块（天空、树干、草坡），线条粗而稀疏，特征点少但分布均匀，对图像识别较友好；唯一较密的区域是树冠与草地短线纹理。

## 2. 权杖七（Wands 07）→ 对应"02_红_愤怒_抬手"

- 主体与姿态：人物双腿大幅分开站稳，双手高举一根权杖，作奋力格挡/迎击状，动作张力和"抬手/愤怒"的攻击性情绪契合。
- 主色调：青蓝天空为底，人物绿衣 + 橙红腿部/靴子，六根橙棕权杖竖立，整体对比强烈、偏暖的紧张感。
- 细节密度：中等——权杖数量多（共 7 根）且布满画面，枝节小叶重复出现，线条较 Cups 04 密；但因元素重复、规律性强，灰度化后特征仍清晰，识别友好度中等偏上。

## 3. 愚人（The Fool 0）→ 对应"04_黄_经典_挺立"

- 主体与姿态：人物昂首挺立于悬崖边缘，一腿前伸、双臂展开，肩扛权杖（悬挂包袱），手持白玫瑰，脚边小狗跃起，姿态开放舒展，与"经典/挺立"正向昂扬气质吻合。
- 主色调：明黄色天空占据上半幅，人物花衣绿橙相间，下缘蓝白雪山与棕褐岩石，明快鲜亮。
- 细节密度：三张中最高——人物服装布满花纹、悬挂包袱与太阳光芒线、小狗和山石纹理均很繁密，特征点极其丰富；对 Vuforia 星级最有利，但注意花纹过于细碎可能在灰度后产生大片相近纹理，需实测两两干扰评分。

## 小结（与 2026-09-19 卡面方案的对照）

- 三张卡情绪-姿态映射成立：静坐抱臂=平静蓝、举杖迎击=愤怒红、悬崖挺立=经典黄；缺"紫_神格"一档参考（本轮未提供）。
- 灰度识别友好度预估：Fool（特征最富）> Cups 04（简洁色块，依赖轮廓）≈ Wands 07（重复杆件规律分布）；均需 Target Manager 星级实测与两两交叉干扰评分兜底。
- 构图启示：均为人物居中偏下、上半留天空色块的竖版构图，与已定 70×120 mm 竖直卡面规格一致；天空区干净、人物轮廓清晰，符合"主体姿态可区分"的卡面设计目标。

## 1. Cups_09（圣杯九）

- 主体与姿态：一名戴橙红宽帽的男子交臂抱胸、坐于木凳上，双臂环叠在身前，姿态放松自足；身后弧形排开九只圣杯，形似"橱窗展示"。人物为正面坐姿，不是侧身，但抱臂的慵懒满足感与"平静"主题契合。
- 主色调：明黄色天空/地面为主底，中部一条青蓝色帷幕带，人物衣袍为白底黑细线，点缀橙红帽饰。
- 细节密度与低对比区：中部帷幕与人物衣袍线条极密，而上下两块大面积黄色平涂区对比度低且空旷；整体灰度后黑线密集区与黄色平区反差明显，Vuforia 灰度识别友好度中上——注意黄色区灰度后为中灰，与米白卡边区分度一般。
- 改编建议：借"抱臂坐姿 + 身后成排杯物"的满足感构图，改画奶蛙侧身抱臂、眯眼微笑，身后弧形排一列小鱼干/碗作为卡面装饰带。

## 2. Pentacles_09（星币九）

- 主体与姿态：一位戴红帽的贵族女子立于繁茂葡萄园中，右手托一只停着蒙眼隼的手套，左手轻拨一枚星币，长裙垂地、体态闲适优雅——站姿微侧、重心放松，与"侧身慵懒"最接近的一张。
- 主色调：黄底天空 + 人物米黄印花长裙为主体亮色，中部大片深绿葡萄藤与紫葡萄构成中暗色带，星币为黄底黑五角星。
- 细节密度与低对比区：中部藤蔓、裙上碎花纹样细节极密且明暗交错，上部黄色天空是低对比平区；灰度后裙摆碎花与藤蔓容易糊成一片中等灰度纹理，特征丰富但局部可能过密，Vuforia 友好度中上，需保证灰阶直方图拉开。
- 改建建议：取"园中闲立 + 一手托物 + 身侧散落星币"的富足构图，改画奶蛙侧身立于草丛，头顶停一只圆鸟，脚边弧形散放五枚星纹圆币。

## 3. 14 Temperance（节制）

- 主体与姿态：长着巨大红蓝双翼的大天使立于水陆之间，低头注视双手所持的两只金杯，正将一杯水倾入另一杯，水流呈折线往来于两杯之间；一脚踏在岸石、一足浸入水中，姿态宁静专注，气质与"平静"完全一致。
- 主色调：米白/灰白底色占大面积，人物白袍居中，双翼红蓝相间为最强色块，下方青绿水波与绿色鸢尾花丛，左上金黄太阳。
- 细节密度与低对比区：白袍上只有稀疏竖线，是全三张中低对比纯色区最大的一张（袍身近全白），两翼与花草细节密、灰度后对比强；中央白袍区特征稀疏对 Vuforia 是减分项，但两翼与底部纹样可补救，友好度中等——若采用需在袍区加淡纹或图案。
- 改建建议：借"双杯倒水 + 一足点水"的平衡意象，改画奶蛙侧身捧两杯、一爪踏水面，背后展开一对小蛙蹼翼作为卡面识别主特征。

---

## 小结

- 三张中 Pentacles_09 姿态与"侧身慵懒"契合度最高，Cups_09 次之，Temperance 气质最"平静"但姿态偏正面站立。
- 共同风险：RWS 黄底大面积平涂区灰度后为中灰、特征稀疏，做卡面时主识别特征应集中在人物与前景物件带。
- 下一批建议优先补看姿态更明确的侧卧/斜倚类牌面（如 Four of Swords）作对照。

## 1. RWS1909 - 16 Tower（高塔）

- 主体与姿态：黑色天空中高塔被黄色闪电击中、顶端金冠飞落起火，两名人物一左一右头朝下从塔上坠落，橙衣者双臂张开、肢体呈失控翻滚状——姿态剧烈但非"抬手"而是"坠落"。
- 主色调：黑底 + 灰白云 + 灰塔，点缀明黄（闪电/落叶/皇冠）与橙红火焰，对比极强。
- 细节密度与低对比区：中高密度，大面积纯黑底是强对比深色区，灰白塔身与云为浅色区，灰度直方图两极分化、特征点丰富，Vuforia 灰度友好度高。
- 改编建议：借"黑底 + 火焰四溅 + 剧烈动态剪影"的爆炸式构图表达红色愤怒的爆发感，但把坠落人物换成愤怒抬手姿，避免负面坠落意象。

## 2. RWS1909 - Wands 05（权杖五）

- 主体与姿态：五名青年各举一根带叶木杖互相挥打缠斗，人群呈团状混战，多人手臂高举过顶——是四张中"抬手"最贴题的一张，但为多人而非单角色。
- 主色调：浅青蓝天 + 五彩人物衣（橙红/黄/绿/白点），地面土黄绿，整体明快偏暖。
- 细节密度与低对比区：高密度（人物肢体与木杖交叠、线条繁密），顶部天空是最大低对比浅色区，中部过密反而可能稀释特征分布；灰度下衣色差异仍在，友好度中上。
- 改编建议：取"高举手臂挥杖"的单人姿态与"杖头发芽"细节，改为单只奶蛙举杖/举爪的愤怒演出，留出干净的天空区保住对比。

## 3. RWS1909 - Wands 12（权杖骑士）

- 主体与姿态：骑士着黄底花纹罩袍与银甲，骑红鬃骏马向左疾驰，右手高举权杖过顶——单主体、明确的"高举手臂"姿态，动势（奔跑的马）呼应愤怒的冲动感。
- 主色调：浅青蓝天空占上半幅，人物明黄 + 橙红马鬃火焰纹 + 粉红马身，底部金黄沙漠。
- 细节密度与低对比区：单主体构图，天空为大面积低对比浅色区且无杂线，主体边缘黑描边清晰、内部花纹中等密度——Vuforia 灰度识别友好度全场最佳。
- 改编建议：直接套用"单主体居中偏上 + 高举手臂 + 大片干净浅色背景"的版式作为红卡构图模板，把马与骑士换成愤怒抬手奶蛙。

## 4. RWS1909 - 08 Strength（力量）

- 主体与姿态：白衣女子头戴花环与无限符号，俯身合掌轻合橙红雄狮的大嘴，姿态温柔俯就、无抬手动作，与"愤怒"主题气质相反（以柔克刚）。
- 主色调：大面积明黄底 + 白裙 + 橙红狮子 + 底部青绿草地，明快温暖。
- 细节密度与低对比区：中部主体密度中高，上方与右侧为大面积纯明黄低对比区；狮子卷毛提供充足局部特征，灰度下黄底偏亮、黑白分布尚可，友好度中上。
- 改编建议：黄底大留白的版式值得借鉴（利于特征集中于主体），但"合嘴安抚"的语义不符愤怒卡，可改为黄底上怒目张爪的奶蛙，狮子元素可舍弃或化作怒气符号。

## 02 高女祭司 The High Priestess

- **主体与姿态**：正面端坐于黑/白双柱（B/J）之间的宝座上，头戴新月三重冠，神情平静直视观者；身披浅蓝长袍，膝上持半卷 TORA 卷轴，脚边一弯黄色新月。姿态端正居中、对称构图，与"端立白眼"的静态神性气质同源。
- **主色调**：浅蓝（长袍、背景拱）＋ 黑白双柱 ＋ 米白底，点缀石榴的黄红与袖口橙色。
- **细节密度与识别友好度**：细节密度中等偏高；大面积低对比纯色区主要是长袍浅蓝区与右柱米白区，但都有线稿纹理，灰度下黑白柱与米白柱对比强烈，整体友好度**较高**。
- **改编建议**：借"居中端坐 + 双柱对称框 + 头饰强调神性"的骨架，把奶蛙置于双柱之间端立、白眼望天，头部留出大面积装饰冠增强构图重心。

## 04 皇帝 The Emperor

- **主体与姿态**：正面端坐石质宝座，白须老人，头戴金冠，一手持安卡权杖、一手握宝球，正襟危坐直视观者；宝座扶手与靠背有公羊头雕饰，背景橙红与灰黄山石。
- **主色调**：橙红（背景与袍）＋ 土红披肩 ＋ 金冠灰座，整体暖色浓重。
- **细节密度与识别友好度**：细节密度高（排线密集）；大面积低对比区少，仅宝座灰面与背景橙红块过渡区略平，灰度后中心人物与边框对比充足，友好度**高**。
- **改编建议**：参考其"正面对称坐姿 + 权杖/宝球双手持物 + 头顶王冠"的权威感模板，为紫蛙设计持杖端立姿，用对称持物强化"神格/上位"的辨识点。

## 05 教皇 The Hierophant

- **主体与姿态**：正面端坐于两根雕花柱之间，头戴三重冠，右手举起作祝福手势、左手持三重十字杖；身前台阶下有两名背对观者的侍从，脚边放交叉钥匙。举手上扬的对称礼仪姿态庄重威严。
- **主色调**：橙红大袍为主体 ＋ 灰柱米白底 ＋ 金冠黄饰，红/灰对比为主。
