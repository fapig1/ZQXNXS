- **卡面适配建议**：最贴合 **①平静款（松弛微笑）** 或作为"官方基准站姿"。若四款分配，其"背手 + 微抬下巴 + 平静神态"也可作 **③神格款（超然）** 的候选；具体分配见文末总结。

## 总结一：7 张图与我们冻结的三维奶蛙形象是否一致？

**结论：7 张全部是同一角色的同款画风，没有混入其他角色；但与工程里冻结的 pet01.blend 三维模型存在系统性色差与比例差，做"形象基准"可用，做"渲染基准"不可直接用。**

1. **角色一致性**：7 张均为奶蛙（黄色梨形身体、奶白大肚皮、绿圈黑瞳大眼、喙状小嘴、棕手棕脚、无外显服饰），角色辨认无歧义。没有一张是别的角色或别的画风；ref_wave 与 ref_rolling 是黑底抠图版本，ref_smiling 画质偏软，但仍是同一角色。
2. **与冻结三维模型（黄绿身体、胖肚子、绿眼）的对照**：
   - **色相偏黄**：参考图身体是纯正暖黄（腿部橙黄），冻结模型描述为"黄绿身体"。卡面用色需明确以哪边为准（建议以参考图的暖黄为准，模型贴图向参考图校色），否则四款肤色扩展中"红/蓝等肤色变体"会失去统一基色。
   - **肚皮形状不同**：参考图肚皮是一大块上宽下圆的斜置色斑（几乎覆盖整个腹面），冻结模型的腹部设计截面为"宽 0.132 m、厚 0.110 m 的鼓肚"，视觉上模型的肚子是"整圈鼓出"，参考图是"色斑 + 鼓肚"并存。属可接受的同类差异。
   - **嘴形差异**：参考图嘴线整体偏"细长微垂/微张"，模型 Idle 嘴形更短平。表情贴图方案（2D 贴图走表情）可以吸收这一差异。
   - **手脚棕色**：与模型一致的方向，但参考图手脚棕色更深、末端渐变更重。
3. **需要修正描述的图**：ref_front_t1 并非"正视镜头"，实为 3/4 侧面扶肚站姿，与 ref_standing 姿态几乎重复；ref_wave 是"招手/马步抬臂"而非"单臂笔直上举"；ref_rolling 是横构图躺倒大笑且画面上半大片留黑。三条均建议同步修正清单描述。

## 总结二：四张卡面基准的分配建议（构图互不趋同）

按"姿态差异最大化 + 表情差异最大化"分配：

| 卡面 | 首选图 | 理由 |
| --- | --- | --- |
| ①平静款（松弛微笑） | **ref_smiling.png** | 唯一明确上扬微笑嘴线的正面图；双手背后、松弛。缺点是半身构图与画质偏软，做卡面时需补全或裁切设计化处理 |
| ②愤怒款（抬手憋怒） | **ref_wave.png** | 马步 + 抬臂手势与愤怒梗图同构，黑底高对比利于 Vuforia；表情可用贴图改成皱眉憋怒 |
| ③神格款（正面端正、超然） | **ref_front_t6.png** | 3/4 正面、微仰视、俯视镜头的"得意超然"感现成；露齿憨笑可收敛为浅笑；是四张里唯一正面 + 全身 + 表情丰富的图 |
| ④经典款（日常/初始感） | **ref_standing.png**（备选 ref_hero.png 或 ref_front_t1.png） | 扶肚放空的日常闲站感最贴"初始状态"；与另外三张的背手/马步/交握姿态区分明显 |

- **ref_hero.png** 作为全局"官方站姿基准"保留：色形最标准、画质最好，建议用作四款卡面共用的形体校对基准（比例、配色、光影方向），也可在①或④与首选图冲突时顶替。
- **ref_rolling.png** 与 **ref_front_t1.png** 不建议直接进四款：前者横构图、留白一半、情绪是"大笑"而非四款任何一个（可留作③神格款"降格演出"或②愤怒款"气到打滚"的衍生素材）；后者与 ref_standing 姿态趋同，留作备胎。
- **构图检查**：四张首选分别是"正面半身微笑 / 侧面马步抬臂 / 正面仰视捂肚 / 侧面扶肚站立"，两两朝向、四肢、表情均不同，去色后剪影差异大，满足"卡面构图互不趋同"与 Vuforia 特征区分的初步要求。最终仍需做去色交叉干扰评分与星级 ≥3 验证。
