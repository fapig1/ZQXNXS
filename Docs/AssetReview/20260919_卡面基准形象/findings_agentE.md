## 1. 骨骼与姿态（实际用到的骨骼与旋转）

骨骼命名先经 `work/list_bones.py` 枚举（26 根骨骼，见 `work/list_bones_log.txt`）。姿态工具两个原语：

- `rot(bone, world_axis, deg)`：绕骨骼当前 head 的世界轴旋转；
- `aim(bone, target_dir)`：把骨骼指向指定世界方向（绕 head 旋转，不变长）。

## 2. 材质改法（只改渲染副本）

- 皮肤换色走**贴图变体**而非改 BSDF 颜色：`work/make_skin_variants.py` 按 HSV 分类把原贴图的"身体/肚皮"区域重映射（身体换色相/饱和/明度并保留明暗起伏，肚皮只换色相/饱和），生成 `work/tex_variant/Pet01_BaseColor_{calm,rage,divine,classic}.png`。渲染时把变体贴图接到 Pet01_Skin / Pet01_Oral / Pet01_Eyes 三个材质的 Base Color（图像纹理节点替换，网格/UV/权重分布不动）。
- calm 身体最终参数 hue 0.585 / sat 0.64 / val 0.40（初版 0.60 明度太亮，灰度下与米色背景只差 30，详见 §5 迭代）；rage 身体 hue 0.030 / sat 0.72 / val 0.68，肚皮保持奶白；divine 身体 hue 0.740 / sat 0.48 / val 0.55，肚皮淡紫；classic 身体 hue 0.115 / sat 0.62 / val 0.70，肚皮奶白。
- divine 的 Pet01_Eyes：Base Color 断开贴图改纯白，Emission Color 白、Emission Strength=6，渲染出泛光白眼。
- 灯光：Key 26W 暖白 / Fill 10W 冷白 / Rim 45W 背后轮廓光 + 0.15 强度微弱环境光，EEVEE（Blender 5.1.1 内置），成片 64 samples + denoising，Standard 视图变换，透明底 PNG。

## 3. 权重问题的根因与处理（本次最大技术障碍）

**根因**：Meshy 生成的网格是单一连续曲面，**手指和前臂内缘与肚皮表面是焊接在一起的（手指下方没有第二层表面）**，且 Meshy 自动权重在手臂链上污染了大量肚皮顶点（诊断见 `work/diag_weights.py`：belly-zone 内 1306 顶点带手臂权重）。任何把手/前臂"抬离体表"的姿势都会撕扯焊接面——表现为从肚皮拉到手臂的长条白痕（rage）或肚皮暗色撕裂（classic 背手）。试验过：距离阈值清权重（阈值 0.025 太松致撕扯）、UV 采样按肚皮色剥权重（修好一处 UV v 翻转 bug 后仅 5 顶点命中，说明焊接面本身被手指色 UV 覆盖）、权重拉普拉斯扩散（撕扯面变大更难看）、删手指+补洞（补洞边界毛糙且前臂内缘仍撕）、Bone Heat 重算（肚皮变形更差）、切桥接面（开洞证实无底层表面）。

**最终处理**（均只作用于渲染副本，不回写冻结资产）：

1. 权重清理：剥掉"肚皮色 UV 顶点 + 距手臂骨骼 >0.02m 顶点"上的手臂权重（每次渲染前在会话内执行）；
2. Corrective Smooth 修饰器 factor 0.85；
3. **姿态设计上让手只沿体表切向滑动、不抬离体表**（rage 外撑、classic 放弃背手改扶肚）。

### 9.3 最终手术管线（work/pose_render3.py，会话内处理，每次从冻结副本重载）

1. **切焊**：删除 Forearm/Hand 0.030m 或 UpperArm 0.030m 内的全部混合面（643 张，肩桥豁免已取消以彻底分离）。
2. **环分类与填充**：删除后逐边界环处理——body 环用 holes_fill 生成 N-gon；**大臂环（>60 边，两条 134/140）同样填充为膜瓣**，彻底密封开口（否则未填充环在掠射角下沿整条缝合线露出内腔暗色锯齿带）；小环（手部 6 张）同样填充。holes_fill 拒填时以 contextual_create 兜底。
3. **body 侧补丁**：细分 cuts=3，内点做 Kasa 球面拟合投影（r≈0.047m, rms≈3.4mm）→ 近邻平滑 → 再投影 → **径向钳制**（内点径向距离 ≤ 最近原始 body 顶点径向水平 −0.5mm，杜绝补丁鼓出体表）→ **切平面钳制**（距最近 body 顶点 <12mm 的内点压入局部切平面内侧 0.5mm，体心径向近似法线）→ 羽化回混。
4. **arm 膜瓣**：细分 cuts=3（大环）/2（小环）→ **均匀深内缩**（全部内点向最近臂骨收 min(4mm, 0.8×距离)）→ 切平面钳制 → 平滑。膜瓣藏入手臂体积内，透过缝隙可见时读作手臂内侧皮肤。
5. **UV**：body 补丁逐 loop 取 z 加权最近 body 顶点(armw<0.2) 的 UV；臂膜用前臂区平均 UV（体色）——**不得**逐顶点采样最近臂顶点 UV（会采到肚皮白色 texel，形成白色撕裂扇）。
6. **材质**：所有手术面（body 补丁/臂膜/残余面）使用 `Pet01_SkinFill` = Pet01_Skin 克隆 + 纹理自发光 0.22（Emission Color 接同一纹理节点），使掠射角/阴影中的补丁面保持可读肤色而非死黑；apply_skin 每姿态同步刷新其贴图。
7. **收尾**：残余环 contextual_create（豁免口部）→ dissolve_degenerate(0.01mm) → normals_make_consistent。
8. **权重**：armw>0.5 顶点 → 本侧 UpperArm/Forearm/Hand 逆距离平方满权重；armw<0.5 顶点 → 剥手臂权重归一化。Corrective Smooth 0.85。
9. **快照防重捕获**：每个环填充/细分/移动完成后，将当前全部面的位置键集合并入快照，防止后续环把先前细分子面重复捕获（重复赋 UV/重复细分）。

**关键工程教训：每个姿态必须用全新 Blender 会话单独渲染**（`-- final <pose>`）。同一会话内顺序渲染多姿态时，clean_weights 等会话状态跨姿态累积，污染后续姿态——表现为沿整条缝合线的暗色锯齿带（且 96 样本下清晰、24 样本被降噪器掩盖，极具迷惑性）。单姿态单会话渲染后该问题消失；rage 的正确宽高比应为 0.605（被污染轮为 0.563）。
