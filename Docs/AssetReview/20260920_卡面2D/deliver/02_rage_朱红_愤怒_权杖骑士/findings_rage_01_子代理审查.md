## 一、逐条核实用户三不满

### 1. 盔甲没有套在奶蛙身上 —— 完全成立，实际情况比"没穿好"更严重：**一件都没有**

青蛙身上**零盔甲**。逐项核对塔罗原稿（对照图 A）中的骑士装备：

| 盔甲部件（原稿 A 中有） | 初稿实际情况 |
| --- | --- |
| 闭合式头盔 + 火焰形羽饰 | 无。头顶直接是 dome 眼，无任何头饰 |
| 锁链领 / 护颈 | 无 |
| 带纹样的黄色罩袍（surcoat） | 无 |
| 胸甲 | 无。胸前只有奶油白肚皮斑 |
| 肩甲（pauldrons） | 无。肩头是光秃秃的橙色皮肤 |
| 护臂 / 护手 | 无。前肢为光皮肤 + 奶油色圆掌 |
| 腿甲 / 靴 | 无。后肢光皮肤 + 奶油色宽脚 |
| 披风 | 无 |

初稿中与"骑士"身份相关的只有两件道具：高举过顶的发芽木杖、左手（画面左侧）牵着的一根缰绳。**不是"盔甲画在了别处或漂浮"，而是整类元素缺失**——盔甲从未出现在角色身上。按本轮设计（"按塔罗骑士主题，本卡允许青蛙穿盔甲，是相对其他卡的刻意设计"），这一条完全没执行。

### 2. 赤色的马变成了呆滞的木马 —— 完全成立，且是"木制摇摇马"，比预期更糟

初稿的马是一具**木制摇摇马（rocking horse）**，细节：

- 材质：浅棕/原木色平板身躯，粗黑描边，身上画有木纹刻线，明确是"木头"而非"活物"
- 底部是**弧形摇椅底座（rocker）**，这是儿童摇摇马的标志性结构，语义上直接等于"玩具"
- 鬃毛与尾巴是同色木片刻线，无毛发飘动感
- 无肌肉结构，躯干是几块平板拼合的玩具造型；眼睛是木刻小圆点，无眼神
- 姿势：前蹄抬起的摇摇马标准静止造型，**无冲锋动势、无腾空尘土、无世界跟踪式的力量线**

与对照图 A 的差距：原稿是一匹**活的栗色骏马**——前蹄腾空、胸部与后腿肌肉隆起、鬃毛和尾巴飘起、有活物的眼神和鼻孔。初稿把这匹活马整体降级成了"儿童房木马"，丢掉了全部肌肉、动势与生命感。附带问题：摇摇马的"玩具"语义与"愤怒 / 威武"主题直接冲突，即使盔甲补齐，这个底座也会继续拖垮气势。

### 3. 整体基调必须威武 —— 成立，当前是"手工木刻玩偶"而非威武雄壮

当前画面气质偏童趣、手作、静。导致气势不足的具体元素：

1. **木马 = 玩具感**（见上，单项就足以定性）
2. **青蛙端坐、无前倾**：身体近乎竖直坐在马背上，没有"向前冲锋"的身体前倾；一腿后蹬的动势很弱
3. **无飘动元素**：原稿的火焰形羽饰、披风在初稿中全部缺席，画面缺少横向动势线；唯一的斜线是高举的木杖
4. **构图居中对称偏静**：蛙与马大致沿竖轴居中，唯一动势元素是木杖和背景放射线，撑不起"冲锋"
5. **表情平静**：大眼 + 短平线嘴，情绪是"呆萌"而非"暴怒"（注：愤怒卡保留反差萌表情是待用户拍板的开放项，见第六节；但即便保留平静表情，其余动势元素也应补足）

用户不满 3 成立，且其根因主要是 1（木马）和盔甲/披风缺失，不是单纯"画得不够凶"。

## 三、风格、边框、文字、明暗

- **木刻平涂**：大色块、粗黑描边、硬边，无写实光影、无渐变、无发光、无模糊。通过。
- **细纹**：背景细密点刻满幅铺匀，无大片空白；蛙身与马身为纯平涂（与锚点做法一致）；底部沙漠黄色区的点刻略疏，可接受。两片标题带按设计留空，不计入空白。

- **标题带与牌位**：顶部中央空牌位、底部约 1/5 空标题带，均为空。通过。

## 六、结论

**不可采用。** 这不是"微调"能解决的版本，三处根须问题：

1. **盔甲**：零盔甲，需从"新增整套贴合身体的盔甲"做起（含头盔/胸甲/肩甲/护臂/披风/靴），并加"防漂浮"硬约束。
2. **马**：木制摇摇马需整体换成有肌肉、有眼神、有动势的活战马，同时删掉弧形摇椅底座这个"玩具"语义来源。
3. **气势**：补前倾身体、后扬披风/羽饰、蹄下尘土与斜向动势线；表情是否从"平静反差萌"改为"怒意"留待用户拍板（若保留平静表情，建议至少确保嘴型为两端微扬的微笑弧线，修正当前的平直短线）。

尺寸与比例（1049 × 1500）无需调整，风格与边框已与 classic 锚点对齐，这两项可在下一版直接继承。
