## 历史制作方法（gpt-image-2.5，定稿后不自动重跑）

1. **风格锚点已定**：classic 成品（2026-09-20 用户确认“非常合适”）已复制到 `picked/classic.png`，分类目录内另留档 `04_classic_暖黄_经典_星币侍从/标准卡面_classic定稿.png`。
2. **再出 calm / rage / divine**：`gpt-image-2.5-flare`，quality `medium`，size `784x1120`，background `opaque`，各附三张参考图（塔罗原稿 + 立绘 + `picked/classic.png`），粘贴该目录提示词。gpt-image-2.5 跨次生成会漂移，必须用定稿卡锁风格、不要只靠文字复述；API 用 `images.edit` 传图，ChatGPT 直接附图+粘提示词。
3. **定稿**：`gpt-image-2.5-sunburst`，quality `high`（不够再 `xhigh`），size `800x1136`，裁到成品 **780×1110 px（66×94 mm @300 DPI）**——适配 **70×99 mm 内径卡片保护套**（左右各约 2 mm、上下约 2.5 mm 间隙，**不做出血**）；Vuforia ImageTarget 尺寸相应为 **0.066×0.094 m**。
4. **改图一回合只改一处**：每个提示词文件里备好了迭代片段（`Only change X. Keep everything else exactly as it is.`），改完把成品回传给下一轮。
5. 出图后命名 `calm_01.png` 等存回 `../raw/`，在 `../raw/生成记录.md` 登记（提示词版本按各卡实际：rage 为 **v6.4 + v6.6**、divine 为 **v6.5**、calm 为 v6.2；记录模型/size/quality 与喂图清单），定稿复制到 `../picked/`。

## 必须守住的设计底线

- **零文字**：画面不得出现任何字母、数字、罗马数字、标题、水印（该模型文字渲染能力强，提示词里已显式禁止）。
- **角色严格复刻立绘**：奶蛙是定死的原创形象（无脖一体钟形轮廓、圆腹最宽、米色连指手 + 三趾宽脚无蹼、头顶 dome 大眼 + 极大黑瞳、恬静微笑嘴、哑光黏土），**不是普通青蛙/写实青蛙**——提示词 Subject 段已写死，出图后先核对长相再往后走。微笑与黑瞳为 2026-09-20 用户决策，优先于 3D 立绘的平直线嘴。
- **生成图零文字、上下文字区为空是设计**：标题带与顶部牌位刻意留空，中文标题/编号由本项目脚本在成品上排版（模型文字渲染位置不稳，且少一块干扰有利于 Vuforia 识别）。
- **风格锚点 = classic 定稿**（2026-09-20 用户确认）：calm / rage / divine 三张以 `picked/classic.png` 为 Image 3，只借风格/边框/纹理密度/渲染方式，配色与构图按各自主稿。
- **背景明度四档**（亮/中深/近黑/深灰）是 Vuforia 灰度区分的设计，与塔罗原稿底色相反，不是画错。
- 立绘只锁长相，**姿态以塔罗牌为准**（classic 举币、calm 倒挂与立绘姿势不同，是刻意融合）。
- **rage 卡独有元素（v6.4 起写死，其余三卡没有）**：全套盔甲穿在奶蛙身上（开面头盔 + 火焰羽饰、锁链领、圆胸甲、圆肩甲、护臂、火焰纹短披风、踝甲——每片甲贴合圆身，不遮奶油白肚皮/连指手/三趾脚/脸）+ **活战马**（栗红棕、明显暗于蛙身）+ 威武冲锋基调（前倾、披风羽饰后扬、蹄下尘土、斜向动势线）。**不要木马/摇摇马**（无木纹、无平板身、无弧形摇椅底座），盔甲不得漂浮脱开；**表情为大张怒吼嘴**（愤怒形态，2026-09-21 用户拍板 v6.6：横向大椭圆张口、暗红褐平涂口腔、嘴角水平/略下扣绝不上扬、上排小圆角三角牙、圆睁直视眼不得眯弧；设计依据为角色表情包实证，见该目录 `findings_表情参考_奶蛙表情包.md`）——这是四卡中唯一不使用恬静微笑的卡。
- **divine 卡独有元素（v6.5 起写死，其余三卡没有）**：教皇袍服穿在奶蛙身上（奶白长袍金边领口、前襟敞开露奶油白大肚皮；深紫圆罩袍覆肩背、胸前圆金扣、金滚边；三十字胸前垂带呼应三重十字杖）+ 三重冠（冠坐头顶、脸和两只纯白椭圆眼全露出）+ 庄严端立对称气场。下摆宽不过圆腹、停在脚上（短腿与三趾宽脚可见）、连指手裸露；袍服不得漂浮脱开，不得遮脸/白椭圆眼/肚皮/连指手/三趾脚；眼睛仍是纯白椭圆无瞳（神格设定，v6.2 不变）。
- 青蛙只许单脚勾枝倒挂——**不要绳索、绳套**。
