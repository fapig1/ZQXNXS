## 一、逐图观察记录

### 1.1 四张定稿卡面

- **classic.png（暖黄）**：直立挺胸，双臂高举过头捧一枚金币置于头顶前上方，头明显上仰望币（约 20~30°），双目上视，嘴小而上扬。姿态语义"展示/献宝/得意"。金币与钱袋是卡面道具，无对应三维网格。
- **calm.png（湖蓝）**：单脚倒挂在树枝上，双臂交叉抱于腹前，双眼闭合成向下弧，头微仰靠，背后放射状光环，旁悬茶杯。语义"彻底佛系"。倒挂涉及 Root 倒置，不可直接三维化。
- **rage.png（朱红）**：骑乘前跃的战马，戴盔甲与火焰盔缨，右臂高举木杖，身体大幅前倾，嘴大张怒吼（白牙可见），眉怒目圆睁。语义"冲锋怒吼"。马、杖、盔甲均为卡面道具，不可三维化；怒吼脸与怒眉可提取。
- **divine.png（紫）**：正面完全对称站立，头戴三重冠，左手持十字权杖，右手举至胸侧、掌心向外五指张开（祝福手势），纯白无瞳之眼，嘴短平直线，身披罩袍，台阶上有交叉钥匙。语义"神格祝福"。冠、杖、袍为卡面道具；"单手举起掌心向外 + 白眼 + 正面对称"是可直接提取的核心姿态。

### 1.2 模式切换梗图

- **meme_calm.jpg**：3/4 侧面，弓身含胸，头回转越肩看向镜头（转头约 40~50°），绿色圆眼直视，嘴角小微笑。可提取"回头一瞥"的头部动作。
- **meme_rage.jpg**：3/4 侧面，单臂向侧前抬起至约肩高、掌张开向前（喝止/制止手势），另一手扶在腹侧，双眼圆睁上视，嘴短平直线。怒意靠眉眼，身体其实是"张开手臂喝止"而非握拳。
- **meme_divine.jpg**：正面正中对称，双臂垂于体侧微外张（气场站姿），胸口前挺，双眼为发光白球无瞳，嘴小微笑上扬，全身带辉光。可提取"正面对称 + 白光眼 + 辉光"的神格表达。

### 1.3 官方姿势图

- **mf-pose-wave.png**：宽距站立，左臂向侧上方举起（约与肩平或略高，掌张开挥动），右手握拳收于腹前，头正，嘴微张微笑。**单臂挥手的直接依据**，手臂外展角约 80~90°（实现时建议上限降至 45° 左右）。
- **mf-pose-rolling.png**：仰卧四脚朝天，双爪搭腹，头后仰张嘴大笑（上排白牙+暗口腔+粉舌）。**整只翻倒 = Root 大旋转，红线素材**，仅可提取"笑到最开"的脸部贴图。
- **mf-pose-lying.png**：俯卧贴地，胸口抬起、头前伸上抬约 30~40°，双臂收于胸下，双腿后伸，嘴角小微笑。全身俯仰约 70~80°，**红线素材**。
- **mf-pose-belly.png**：宽距站立，双手背到腰后（反手叉腰），挺胸挺肚，嘴小张吐粉舌，双眼圆睁。可提取"挺胸吐舌的得意/俏皮"脸与"挺胸"身体姿态；双手背后是肩大幅后旋，风险高。
- **milkyfrog-hero.png**：3/4 站姿，双臂自然下垂贴身微后，下颌微抬，嘴角小微笑，整体挺拔。可提取"端立挺胸抬头"作为 divine/得意类动作的起手与收势基准。

### 1.4 基础表情包

- **naiwa-smiling.png**：正面站立，双臂隐于身后（背手），嘴大微笑弧，双眼圆睁。恬静满足的正面基准。
- **naiwa-thinking.png**：3/4 侧，单手抬起以指节抵下巴/脸颊（肘大幅屈曲），头微低，双眼圆睁侧视，嘴平直线。可提取"抬手托腮"的思考姿态，手臂前举+屈肘，幅度需压小。
- **naiwa-standing.png**：侧立，双手交叠搭在腹前，头平视，嘴平直线略下垂。可提取"双手搭腹"的安静站姿，也是大笑 t1 的预备手位。

### 1.5 xinye 变体

- **angel.jpg**：背生白色双翼，头顶椭圆光环，双臂抬至胸前两侧、掌心向前上摊开，头微仰约 10~15°，嘴平直小线。**"摊掌 + 微仰头 + 光环"可提取**；翅膀为新增网格，红线。

- **egg.jpg**：一团蛋形身体坐于草窝，仅脸（双眼+小微笑）。提示"缩成蛋形"可用整体缩放/贴图表达，非骨骼动作。
- **kid.jpg**：夜桥上斜倚栏杆，单手抬至嘴边持物，身体后仰放松。倚靠姿态不可用；"单手抬至嘴边"幅度可参考（肘屈曲，前臂近垂直）。
- **meditation.jpg**：盘腿坐，单手竖食指于嘴前（噤声/点化手势），另一手搭膝，眼半闭。盘腿不可用；竖食指依赖指骨，26 骨骼下风险高，见红线节。

- **sad.jpg**：背面 3/4 站立，双手交扣背于腰后，头侧转望窗，嘴平直。**背手站立的清晰侧视证据**；转头看窗外可弱化提取。

- **glimpse.jpg**：3/4 站立，双手按在腹前，双眼向侧瞪视，身体微含。可提取"双手搭腹 + 警觉侧目"的小反应。

### 1.6 大笑逐帧（naiwalaugh_t1~t6）

- **t1**：站姿 3/4，双眼闭合成平静细弧，嘴小微笑弧，双手交叠搭腹前，头平。**完美的大笑预备帧**：吸气收势。
- **t2**：头大幅后仰（约 30~40°），嘴张至最大（横椭圆、上排白牙、暗口腔），双眼挤成开心眯弧，双手贴住腹部两侧，身体后靠。**大笑爆发峰值帧**。
- **t3**：头回正一些（后仰约 15~20°），嘴仍大开上扬，眯弧眼，双手悬于腹前微离。回弹半程。
- **t4**：头反而微前倾（约前倾 5~10°），嘴大开，眯弧眼，双手收拢至腹前相触（拍肚动作）。节奏下行的"前倾拍肚"帧。
- **t5**：再次头后仰（约 25~30°），嘴张至最大，双手交扣按腹。**第二波爆发峰值**，证实大笑是"两波式"节奏。
- **t6**：整只笑倒在地，腿翘起，头侧转，圆睁眼+粉舌圆嘴。**Root 翻倒红线**，不可做，但证实"笑到失控倒地"是角色语义的一部分。

## 二、逐色动作提案

> 通用原则：所有动作用头部/躯干/肩肘**小幅旋转**实现，手脚不离开初始接地/贴身范围；表情全部走 2D 贴图/面片；增强全部走粒子/billboard。每条幅度均为**建议上限**，实际以 FBX 回读不破肚皮为准，允许再降。

### 2.1 classic 暖黄「得意」

**候选 A：得意三连晃（沿用 + 改良）— `classic_proud`**
- 一句话编排：起手挺胸抬头亮出肚皮 → 高潮身体左右各晃一次（三连晃的"三"= 左、右、回中） → 收势单手拍胸/叉腰定住。
- 关键部位与幅度：躯干后仰约 8° 上限 + 头后仰 10~15° 上限（classic.png 望币仰头、milkyfrog-hero 挺拔的弱化版）；左右摇摆各 8~10° 上限、周期约 0.4s/次；收势单侧肩外展 30~40° 上限、肘屈把手带到胸前拍一下或落在髋侧（mf-pose-belly 叉腰、mf-pose-wave 收拳于腹前的弱化混合）。
- 表现：得意眯弧眼 + 上扬微笑弧贴图（naiwa-smiling）；头顶两三颗星点粒子 + 可选金色闪光 billboard。
- 素材证据：classic.png（挺胸仰头望币的得意轴心）、mf-pose-belly.png（叉腰挺胸吐舌）、milkyfrog-hero.png（挺立收势）。
- 与 design_v1 对比：**沿用**其"挺身、左右小幅摆动、回到满足姿态、2.0s"，补充了具体角度上限与"单手拍胸/叉腰"收势细节（design_v1 未给收势）。

**候选 B：献宝挥手（改良备选）— `classic_wave`**
- 一句话编排：单臂举至肩侧上方掌心向前挥两下 → 头随手动微偏 → 收手回腹前。
- 关键部位与幅度：单肩外展 45° 上限（mf-pose-wave 原图约 80~90°，刻意压半防爆面），前臂小幅左右摆 ±10° 上限，头侧倾 5° 上限。
- 表现：圆睁眼 + 微笑弧；挥手处加 2~3 个星光粒子。
- 素材证据：mf-pose-wave.png（挥手本体）、classic.png（举臂展示的语义）。
- 对比：design_v1 无此候选；作为 A 的替代或未来点击反馈动作储备。**理由**：卡面核心语义是"展示"，挥手比摇摆更贴"献宝"，但单臂外展是本模型风险动作，故只列为备选并压幅度。

**候选 C：拍肚得意笑（替换候选）**
- 沿用 social_laugh 的 t4"前倾拍肚"单帧扩为 1.5~2.0s 小动作：前倾 5° 上限，双手交替轻拍肚（肘屈伸 ±10° 上限），得意眯眼。证据：naiwalaugh_t4、mfstream_t6。**理由**：若"三连晃"实机看呆板，可换成更"奶"的拍肚。

### 2.2 calm 湖蓝「佛系」

**候选 A：佛系点头（沿用 + 改良）— `calm_zen`**
- 一句话编排：起手双手交叠搭腹、缓缓闭眼 → 高潮缓慢点头三次（越点越慢） → 收势头回正、睁眼、嘴角微扬。
- 关键部位与幅度：点头为头骨俯仰 +5° ~ -8° 上限（幅度递减：8°→6°→4°），躯干随点头微沉 2~3° 上限，无手臂动作（手臂全程保持 naiwa-standing.png 的搭腹静态，避免牵拉）。
- 表现：闭眼细弧贴图（naiwalaugh_t1 的闭眼、calm.png 闭眼）→ 收势舒展微笑弧；头顶淡蓝涟漪/放射光环粒子缓慢旋转（calm.png 放射光环证据）。
- 素材证据：naiwa-standing.png（搭腹手位）、calm.png（闭眼 + 光环）、naiwalaugh_t1（搭腹 + 闭眼的站姿组合）。
- 对比：**沿用** design_v1"缓慢轻摆、闭眼点头、悠然停顿、2.5s"，补充：点头的幅度递减节奏、手臂保持静态不动的设计决定。

**候选 B：背手远望（替换候选）— `calm_gaze`**
- 一句话编排：头缓慢转向侧方 15~20° 上限望远处 → 停顿一拍 → 缓缓转回，全程身体不动。
- 关键部位与幅度：仅头部水平旋转 15~20° 上限 + 微仰 5° 上限；**不背手**（sad.jpg 的背后交扣手位是肩大幅后旋，红线弱化为不做手臂）。
- 表现：平直嘴 + 半睁眼贴图；可选微风粒子/淡蓝光尘。
- 素材证据：sad.jpg（背手侧望的姿态意境）、meme_calm.jpg（回头越肩的语义）、rain.jpg（仰头放空）。
- 对比：design_v1 无此候选。**理由**：比点头更"故事感"，且是全素材里风险最低的动作（纯头部），适合作为 calm 的低成本替代或第二段。

### 2.3 rage 朱红「兴奋怒吼」

**候选 A：兴奋怒吼（沿用 + 改良）— `rage_roar`**
- 一句话编排：起手身体前倾蓄力、怒眉圆睁 → 高潮头后仰张嘴怒吼 + 双臂向侧上张开 + 全身高频小抖 → 收势身体一沉（跺脚感）回正。
- 关键部位与幅度：起手躯干前倾 5~8° 上限；高潮头后仰 10~15° 上限（比大笑 t2 的 30~40° 刻意收小）、双肩外展 30~45° 上限 + 肘微屈（meme_rage 张臂喝止 + rage.png 举杖的弱化）；高频抖动为躯干旋转 ±2~3° 上限、8~10Hz；收势整体下沉用 Root Y 下移 0.01~0.02m 上限或膝盖微屈表达，不做真抬腿跺脚。
- 表现：嘴用"横椭圆怒吼开口"贴图——**嘴角拉开保持水平或略下扣、绝不上扬**，暗红褐口腔 + 上排小白牙 + 可选圆舌，怒眉 + 圆睁直视眼（画法细节全部按既有 findings_表情参考 第四节执行，本文不重复）；增强：短火花粒子 + 地面冲击环 billboard（rage.png 火焰盔缨的语义转译）。
- 素材证据：meme_rage.jpg（张臂喝止 + 怒眉直视）、rage.png（张嘴白牙怒吼 + 前倾冲锋姿态）、mf-pose-wave.png（张臂的幅度参考）。
- 对比：**沿用** design_v1"轻蓄力、抬头怒吼、回弹收势、2.0s"，补充：双臂张开的幅度上限、±2~3° 高频抖动这一"兴奋到极致"的关键演出层（design_v1 只有"怒吼"没有"抖"），并明确怒吼嘴与大笑嘴的嘴角分界沿用既有结论文档。

**候选 B：喝止一顿（改良备选）— `rage_halt`**
- 一句话编排：单臂猛抬至肩侧、掌向前 → 整只定住 0.5s（急停） → 收手。
- 关键部位与幅度：单肩外展 45° 上限、掌心向前，头前倾 5° 上限瞪视；"急停"用 2~3 帧完成起手 + 0.5s 静止定帧，反差感来自速度而非幅度。
- 表现：怒眉圆睁 + 平直嘴贴图；掌前加一圈短促冲击波 billboard。
- 素材证据：meme_rage.jpg（单臂喝止手势本体）、mf-pose-wave.png（掌向前）。
- 对比：design_v1 无此候选。**理由**：更贴 meme_rage 的原始梗义；若 full 怒吼在多宠同屏时太吵，可降级为此。

### 2.4 divine 紫「神格觉醒」

**候选 A：神格觉醒（沿用 + 改良）— `divine_awaken`**
- 一句话编排：起手低头敛目静止 → 高潮极缓抬头 + 双眼渐变为纯白发光 + 双臂向两侧缓展 + 光环光柱渐显 → 收势定住庄严站姿 1s 后归位。
- 关键部位与幅度：低头 5~8° 上限 → 抬头至后仰 10° 上限，用时≥0.6s（庄严感=慢）；双肩外展 30~40° 上限、掌心渐转向前方（angel.jpg 摊掌、divine.png 祝福手势的弱化，原图外展更大，刻意收小）；躯干挺直微挺胸 3~5° 上限（milkyfrog-hero 端立）。
- 表现：闭眼/垂眼贴图 → 纯白无瞳发光眼贴图切换（meme_divine 白光眼、divine.png 白眼，是四色中唯一换眼型的专属动作）；头顶椭圆光环粒子渐显 + 缓慢旋转（calm.png、angel.jpg 光环证据）；身后紫金色光柱/辉光 billboard（meme_divine 辉光）。
- 素材证据：divine.png（祝福举掌 + 白眼 + 正面对称）、meme_divine.jpg（白光眼 + 辉光 + 对称站姿）、angel.jpg（摊掌 + 头顶光环的可行组合）、milkyfrog-hero.png（端立）。
- 对比：**沿用** design_v1"端立静止、抬头、慢速回正、2.5s + 紫金光环"，补充：双臂缓展这一层（design_v1 只有头动，正面端立配完全不动手会显得没做完）与"白眼渐变点亮"的时刻设计。

**候选 B：祝福一指（替换候选）— `divine_bless`**
- 一句话编排：单手缓抬至胸前 → 掌心向外定住 → 头微点一次。
- 关键部位与幅度：单肩前举 40° 上限 + 肘屈，头俯首 5° 上限一次。
- 表现：白眼 + 平直嘴；掌心前放一圈柔和光环 billboard。
- 素材证据：divine.png（右手祝福手势本体）。
- 对比：design_v1 无此候选。**理由**：单手版比双臂展开更稳（手臂动作量减半），可作为 A 破面时的保底。

## 三、social_laugh 共同大笑节奏表（依据 naiwalaugh_t1~t5 逐帧）

原素材两波爆发 + 中间前倾拍肚 + 尾帧笑倒（t6 不可用，用回正收势替代）。建议单次 2.2s，与 design_v1 的 2.4s 相容（余量 0.2s 可分配给收势后的静止）：

|---|---|---|---|---|

| 0.30–0.70 | **第一波爆发** | 头后仰，**建议上限 20°**（原图 30~40° 收小），身体后靠 5° | 嘴张至峰值：横椭圆 + 上排白牙 + 暗口腔；开心眯弧 | t2 |

- 嘴部画法严格沿用既有结论文档第二节（横椭圆、暗红褐口腔、上排一排小圆角三角白牙、无下排牙、开心眯眼绑定）。

## 五、结论小结

- **classic**：沿用 `classic_proud` 得意三连晃（挺胸仰头 10~15° 上限 + 左右各 8~10° 两次 + 拍胸/叉腰收势），备选献宝挥手；证据 classic.png、mf-pose-belly、milkyfrog-hero。
- **calm**：沿用 `calm_zen` 佛系点头（搭腹闭眼 + 递减点头 8°→4° + 淡蓝光环），备选纯头部的背手远望；证据 naiwa-standing、calm.png、sad.jpg。
- **rage**：沿用 `rage_roar` 兴奋怒吼并补"±2~3° 高频抖动"演出层（前倾蓄力 → 后仰 10~15° 上限张嘴怒吼张臂 45° 上限 → 沉身收势），嘴形按既有结论文档"嘴角不上扬"分界；证据 meme_rage、rage.png。
- **divine**：沿用 `divine_awaken` 并补"双臂缓展 30~40° 上限 + 白眼渐变点亮 + 光环光柱渐显"（低头 → 极缓抬头 → 定格庄严）；证据 divine.png、meme_divine、angel.jpg。
- **social_laugh**：按 naiwalaugh 逐帧定 2.2s 两波式节奏表（0.3s 预备 → 0.7s 第一波峰值 → 0.4s 拍肚 → 0.4s 第二波峰值 → 0.3s 收势），多宠相位错开 0.1~0.2s；笑倒、捧头两处素材红线不做。
