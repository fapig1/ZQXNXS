# 大笑极限姿态数值探测（2026-09-28）

- 对象：`ArtSource/Characters/Pet01/pet01.blend`，SHA-256 `308d2060…`（探测前后一致，脚本只在内存中摆姿态，未保存）。
- 方法：Blender 后台对静态姿态求蒙皮结果，统计边长拉伸/压缩比（相对静止姿态）、身体自交面（排除眼/睑/嘴嵌套壳）、脚底漂移。仅静态单帧，不含 FBX 回读和连续播放。
- 视觉复核：[findings_极限姿态视觉审查.md](findings_极限姿态视觉审查.md)，渲染图在 `renders/`。

## 现状

- 源文件没有 `social_laugh` Action，Unity 侧也没有；`final_manifest.json` 标记为 `not_made_yet`。“大笑是否到位”目前无动作可查，本文检查的是现有骨架和权重能不能撑住夸张大笑。
- 网格：主体是一个连通壳（7,304 顶点，手臂与身体同壳），眼、眼睑、嘴、牙是独立小壳，由 Head/Eye/Lid/Mouth 骨骼刚性带动。3,601 个顶点是手臂与躯干的混合权重，没有顶点的手臂权重超过 0.82。

## 结果

| 姿态 | 最大拉伸 | >2倍边数 | 最小压缩 | 身体自交 | 结论 |
|---|---:|---:|---:|---:|---|
| 后弯90°（骨盆20/脊柱20/胸25/头35%，大腿反补） | 1.86 | 0 | 0.60 | 0 | 可用 |
| 后弯110° | 1.90 | 0 | 0.57 | 0 | 可用 |
| 后弯90°+纵向拉伸1.2 | 1.92 | 0 | 0.60 | 0 | 可用 |
| 后弯90°+扭转20°/侧弯15° | 1.78 | 0 | 0.53 | 0 | 可用 |
| 前弯40°（捧腹） | 1.34 | 0 | 0.50 | 0 | 可用 |
| 前弯70° | 1.61 | 0 | **0.18** | 3 | 腹部挤压折叠，不用 |
| 后弯90°+双臂外展45° | 2.44 | 50 | 0.50 | 0 | 临界 |
| 双臂外展80° | 3.22 | 57 | — | — | 数值超限（腹部 z≈0.085–0.126m 混合权重区）；渲染未见明显撕裂 |
| 双臂外展120°（捧头） | 3.51 | 136 | — | — | 数值超限 |
| 嘴骨张开 = 既有最大值 | 1.98 | 0 | 0.62 | 0 | 已到上限 |
| 嘴骨张开 ×2 | 3.47 | 8 | 0.44 | 0 | 超限 |

- 躯干平均分配旧方案（骨盆10/脊柱35/胸35/头20%）在 90° 时有 8 条边超 2 倍；改为把弯曲分给骨盆和头之后降到 0。**脊柱链大幅后弯不需要重新绑定。**
- 在内存中对躯干权重做额外平滑（4 次和 12 次）反而更差：后弯 90° 出现 3–4 个自交面，最大拉伸上升。现有躯干权重不是瓶颈。
- 问题集中在**手臂抬起**：超标边全部位于手臂/腹部混合权重顶点（100%）。这正是 2026-09-22 权重修订处理过的区域，40° 以上仍不够。
- 大腿反补骨盆时脚底漂移 3–13mm，做动作时要用脚 IK 或逐帧补偿锁脚。
